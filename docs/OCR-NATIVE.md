# 本地文字 OCR 加速 · 0.2.10

区域识别默认先尝试本地 PP-OCRv4，AUTO 按 NPU → GPU → CPU 选择检测与识别设备；方向分类和字符投影使用 CPU。未安装可选组件、旧服务没有 OCR 能力或后端不可用时，回退已有 Tesseract WASM。后端列表保留直接选择 Tesseract、Texo、HTTP 和图像 LLM。网页/LLM 失败时按保存的本地偏好回退。

0.2.35 起推荐在设置 → 本地模型管理中一键准备通用运行时，并单独下载 OCR 模型，详见 [运行时安装](RUNTIME-SETUP.md)。基础 PDF 功能不需要 Python。下述手动脚本与基准保留作为历史开发记录；轻量公开包不预装模型权重。推理只使用本机资源，不自动下载模型或可视化字体。

## 模型与实现

- [RapidOCR 3.10.0](https://github.com/RapidAI/RapidOCR) 前后处理与 [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) PP-OCRv4 中英移动端模型，Apache-2.0；来源、许可和固定 SHA256 随 `public/models/ppocrv4` 保存。三个模型共 **16,189,007 字节**，不等于整个 Python 运行时大小。
- PP-OCRv4 使用其对应的 [上游检测归一化参数](https://github.com/PaddlePaddle/PaddleOCR/blob/release/2.7/tools/infer/predict_det.py)，避免误用新版模型默认值。
- NPU/GPU 检测输入固定 768×768。最大边 1472px，64px 重叠，每个区域最多四块；先合并概率图，再生成文本框和阅读顺序，避免跨块重复或切断文字。相比原来的整图缩到 768px，测试长行不再漏失。
- 识别宽度固定为 320/640/1280。原始完整识别网络在部分宽度出现 NPU 内存调度失败；在最后的 6625 类字符投影之前拆分后，所用宽度通过本机编译/推理。CPU 保留原投影和 Softmax，原始 ONNX 权重未修改。CPU 拆分与原图数值/argmax 一致性检查通过。
- 超过加速宽度的行使用完整 CPU 识别，超过 4096 输入宽度拒绝并提示缩小区域；不裁掉行尾。最多 128 个文本区域、PNG 4MB/400 万像素、输入边长 8192px、极端长宽比限制和 120 秒推理期限。
- 最多六个 LRU 编译会话，另有一个 CPU 投影会话；CPU 两线程，OpenCV 一线程，编译缓存目标 256MiB。驱动占用的文件可能使缓存暂时超出目标；目标不等于进程总内存。会话使用弱引用，避免闲置释放后仍被循环引用保留。
- Texo、OPUS、OCR 共用单请求锁和单份原生模型生命周期；切换功能释放旧模型，闲置 120 秒释放。取消在阶段/编译前后检查，单次原生编译或推理无法中途强制停止。忙碌、输入错误、取消和超时不会再启动一份 WASM 推理。

## 当前设备验证

设备：Core Ultra 5 238V、Arc 130V、Intel AI Boost；OpenVINO 2026.2.0。可复现脚本：`scripts/benchmark-native-ocr.py`。完整输出见 [12 个合成区域的三设备记录](benchmarks/ocr-openvino-20261011.json)。

同一 1000×370 中英混合区域，暖调用八次的中位数：

| 路径 | 后端总耗时 |
| --- | ---: |
| CPU 两线程 | 166.49ms |
| NPU 检测/识别 + CPU | 116.22ms |
| GPU 检测/识别 + CPU | 108.79ms |

时间包含 PNG 处理、检测/裁切、方向分类、识别和后处理，不包含 UI 截图或模型对象首次构造。该轮复用已有磁盘编译缓存，第一调用不是清空缓存后的冷编译。早期实际编译耗时为数秒，不能用暖调用代表首次体验。

样本包含中英、数字、小字、180° 文字、轻度模糊、窄区域、数学、长行和空白。长行在三个设备上完整保留；小字会漏空格，混合语言空格也会因设备/填充不同而变化；初版还出现数学符号错误。方向分类只调整文字行方向，不推断整张倒置页面的语义阅读顺序。模型分数不是校准的正确率，合成样本也不是扫描件/手写准确率验收。数学继续使用 Texo，真实扫描页、小字与英文空格保留在后续质量清单。

**尚未测量瓦特或电池续航。** AUTO 的 NPU 优先遵循设备偏好，不以这些耗时证明节能。真笔延迟和扩大真实样本仍未完成；Piper 原生适配的后续进展见 [PIPER-NATIVE.md](PIPER-NATIVE.md)。
