# 草稿纸

底部工具条的“草稿”取代“加页”；插入空白页仍在左侧页面面板。

- 每份文档最多十张独立草稿纸，可重命名、切换、设置背景颜色和清空；清空可撤销。
- 草稿保存到 `.tixtab` 工程及本地工作空间。PDF 导出只包含原来的文档页面，后台导出也不会复制草稿数据。
- 工作空间记录每个标签的草稿启用状态、隐藏 PDF 状态、所选草稿及独立位置、缩放。
- PDF 区域和背景分别拖动、缩放；三种视图均支持，适合页面/宽度按钮仍归正 PDF。
- 连续模式在草稿开启时无缝拼接，保留左右阴影，滚动同步页码；进入/退出草稿保留当前视图类型。
- 笔画跨越页面边缘时两侧实时预览，提交时按页面边界拆分到 PDF 和草稿。PDF 区域优先接收笔迹。
- 插入文本、公式、草图和粘贴普通对象时使用视角中心所在的层，保持 PDF 的拖动位置。
- 长按页面缩略图后拖入背景，会生成独立的页面图像对象，保留页面当时的内容和批注；可移动、缩放、调整到手写层前后。该页面对象不可复制/剪切/粘贴；普通对象与笔迹可跨层复制。

## 便签与 OCR 截图

- 草稿便签卡片靠近自身标注区域显示，不按 20,000 单位画布的右边缘定位。卡片保持屏幕尺寸，移动工具可编辑文字、移动卡片和调整锚点；X 关闭卡片，点击锚点可重新打开。
- 便签工具创建一条后自动切到移动工具并选中新便签；其他工具不显示编辑控制点。
- “框选 OCR”支持草稿背景上的笔迹和对象；重叠处优先选取原 PDF。截图只按所选区域分配受限像素画布，跳过区域外的图像解码和笔迹绘制。

## 渲染与资源

草稿是 20,000 × 20,000 单位的方形画布。只挂载选中纸张；笔迹和对象使用空间索引及视口裁剪，实时笔迹仅分配屏幕范围的画布。页面拖动预览复用低清缩略图缓存，落下时按最多四百万像素捕获独立图像。历史记录对唯一 PDF 源及图像数据按内存预算裁剪；重复引用不重复计费。

## 验证

`tests/scratch-paper.spec.ts` 覆盖纸张管理、工程/工作空间恢复、导出排除、三种视图的独立操作、跨边界书写及松手前预览、夜间颜色、连续拼接/页码、拖入预览、复制限制、中心粘贴和画布分配上限。

`tests/scratch-review-capture.spec.ts` 与 `tests/review-keyboard.spec.ts` 补充覆盖草稿便签定位/关闭/重开、移动工具编辑、首次聚焦键盘偏好、三视图背景截图与 PDF 优先命中、区域外图像不解码。
