# Zotero 联动（0.2.26）

在标签栏点击 Zotero；顶部已收起时也可以使用。设置中保留相同入口。

0.2.26 按原生 Zotero 的布局调整为左侧资料库/文件夹树、中间标题/作者/附件分列列表、右侧附件详情。个人库与群组库分开显示，蓝色文件夹图标、真实父子层级、三角展开/收起与行高亮；夜间使用中性深灰配色。顶部显示当前库/分类路径和文献搜索。

点击资料库根行查看全部文献，点击文件夹查看该分类；三角按钮只展开/收起，不改变文献选择。↑↓、Home/End 移动树焦点，→展开或进入子文件夹，←收起或返回父级，Enter/空格选中。底部筛选框匹配已加载的文件夹及祖先路径，清空后恢复原展开状态。文件夹按需分页加载，已加载资料库在当前面板中复用；不后台轮询。收起整个文件夹栏保留本次面板的展开状态。

窄窗口下附件详情移到文献列表下方；可用左上按钮收起文件夹栏以增加文献宽度。触屏行高至少 44 px。尚未加入 Zotero 原生的标签筛选、已保存搜索与文献类型编辑。

1. 启动较新版本的 Zotero，在“设置 → 高级”启用“允许本机上的其他应用程序与 Zotero 通信”。
2. 在 SurfaceTab 打开 Zotero 资料库，选择个人/群组库及分类，搜索标题或作者。
3. 选中文献，再点击 PDF 附件，打开到 SurfaceTab 标签页。附件必须已下载到本机。
4. 可复制文献的 BibTeX，或点击“返回 Zotero”定位原条目。

此实现采用官方[本地 API](https://www.zotero.org/support/dev/web_api/v3/local_api)，只请求 `127.0.0.1:23119/api/`，无需云端 API Key。使用主进程的本地 HTTP 读取，绕过渲染器 CORS 和系统远程代理；不读取 Zotero SQLite 数据库。只在打开面板或用户操作时请求，不后台轮询。文献每批 50 条，分类/附件每批 100 条；可继续加载。群组选择最多显示 100 个群组。

标注与原始 PDF 副本保存在 SurfaceTab 工作空间，工程导出也保存关联信息。带 Zotero Server ID 的资料库重复打开同一附件，会恢复已有 SurfaceTab 文档与标注，避免重复导入。旧版本不提供 Server ID 时，每次重新导入，避免不同数据库的同名标识混淆。Zotero 修改源附件后，已保存的 SurfaceTab 副本不会自动刷新。

当前支持本地读取、PDF 导入、BibTeX 复制及条目定位。尚未实现云端账号接入、SurfaceTab 标注与 Zotero 原生批注的互转、自动覆盖附件或回写笔记。需要分享修改版时使用原有“导出 PDF”。

PDF 附件上限 256 MiB；主进程从 Zotero 返回的本地文件 URL 读取，仅接受 PDF 文件及文件头，不接受任意外部 URL、网络共享或渲染器指定路径。打开时分块读取并支持取消，最后传送至现有 PDF 导入流程；大文件仍会发生字节缓冲区复制。关闭面板、导航或退出终止请求，30 秒无结果时显示取消/超时提示。

连接失败提示区分 Zotero 未启动、未启用本地 API、附件未下载/路径失效、资料库更换及版本不支持。切换了 Zotero 数据库后点击重新连接。浏览器开发预览只显示说明，实际连接需使用桌面版。

0.2.24 的桌面验证使用符合官方接口的临时本地 HTTP 服务、真实临时 PDF 文件、实际 Electron 主进程 IPC 和系统剪贴板。0.2.26 已连接本机真实 Zotero，以只读方式验证个人/群组库、多层文件夹、键盘选择、筛选、收起后保留展开状态、文献/附件详情及夜间竖屏布局；未改动 Zotero 数据或剪贴板。PDF 导入和关联保存继续使用浏览器流程回归，真实客户端的 PDF 导入验收仍待完成。
