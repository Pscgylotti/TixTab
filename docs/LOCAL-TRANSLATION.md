# 本地翻译与快捷面板

2026-10-16，0.3.4 发布后的源码修订。

## 使用方式

- 右下角页面操作按钮展开快捷面板，可打开翻译界面，也可删除本页、清除本页标注、复制本页或插入空白页。
- 翻译界面可直接输入和修改原文，无需先划词。关闭再打开时，本次应用会话的输入、结果和目标语言保留；编辑原文或更换目标语言会取消旧请求并清除旧结果。
- 目标语言右侧显示最近三个目标语言，去重并保存在本地；划词翻译与独立翻译界面共享此历史。
- 打开界面不会自动下载权重或启动模型。首次使用从翻译后端设置进入本地模型管理，下载所选模型及对应运行库。

## Hy-MT2 1.8B

使用腾讯官方 `Hy-MT2-1.8B-GGUF` 的 Q4_K_M，固定 revision `a0c709d9fac510f2c807aa3af52872340dc37a4a`。权重 1,133,080,448 字节，SHA256 `dc5f44fcf1fa496ee7ad725982c0c8c553a4de00259b53af84c4b89fb0c06699`，许可证随模型一起下载、校验。模型不随 lite 安装包分发。

提供两个独立后端：

| 后端 | 设备选项 | 运行方式 |
| --- | --- | --- |
| Hy-MT2 | CPU / Vulkan GPU / 自动 GPU→CPU | 复用已有 Uni-MuMER llama.cpp b11429 运行库 |
| Hy-MT2 OpenVINO（实验性） | CPU / GPU / NPU / 自动 GPU→CPU | 同一份 GGUF 权重，另下载 llama.cpp b11429 的 OpenVINO 2026.4.1 C++ 运行库 |

两种方式均复用现有本地服务，不创建新的 Python 环境，不安装 GenAI/Transformers/PyTorch。界面暂开放中、英、日、韩、法五种目标语言。按官方任务提示构造用户消息，使用模型内嵌聊天模板，不猜测特殊 token；限制输入 10000 字符并检查真实 token 数，避免静默截断。普通设备上下文 8192，NPU 实验路径 2048；为输出预留容量。

取消、超时及父服务退出会关闭隔离的 C++ 子进程。不同本地任务共用一个推理通道和一个常驻模型，切换后端或任务会先释放旧模型；闲置释放沿用用户设置。禁用 llama-server 的提示词内存缓存，不维护全文翻译缓存。

## 验证与限制

- 本机实际运行过原生 CPU、Vulkan GPU、OpenVINO CPU/GPU 翻译，并确认结束后子进程退出；短句结果正常，不代表完成论文翻译质量评测。
- 当前 b11429 OpenVINO 路径遇到 Hunyuan 计算图输入形状缓存不兼容；关闭其进程内编译缓存后 CPU/GPU 可以输出。此兼容设置增加编译开销，当前明显慢于原生路径，不作为默认选项，也不声称加速。
- NPU 为实验选项，驱动、算子及量化兼容性仍需逐机验证。显式选择 GPU/NPU 时，必须确认对应设备实际承载模型，否则报错；不会将 CPU 结果标作 NPU。
- 本次 NPU 短句验证在初始化阶段由原生进程退出，未得到译文；已确认进程释放。本机 NPU 路径未通过，不能声称已支持可用的 NPU 推理，具体失败原因尚未定位到算子或驱动。
- 浏览器路由测试验证了无需划词的输入、关闭重开保留结果、三条历史、请求体与设备路由；单元测试验证拒绝/取消不重复推理及服务切换时关闭旧模型。这些测试与真实推理验证分开记录。

上游：[官方模型](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF)、[官方提示与推荐采样参数](https://github.com/Tencent-Hunyuan/Hy-MT2)、[固定版本 OpenVINO 后端说明](https://github.com/ggml-org/llama.cpp/blob/b11429/docs/backend/OPENVINO.md)。

## 页面与笔触
