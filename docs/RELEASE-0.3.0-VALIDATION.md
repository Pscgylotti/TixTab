## 三轮优化收尾

1. **保存与输入。** 保留公式草稿合并写入（历史实测 253→2 次事务），增量笔迹和完成门槛；当前草稿/重开/撤销回归通过。
2. **渲染与资源。** 保留前景裁剪/几何索引、背景位图与显示所有权复用、严格夜间 GPU 快速路径、有限文本共享（目标提取 30→12）。无整体收益的并发/布局候选已撤回。最终生产流程使用未修改的五份冻结脚本，40 页/3000 笔迹/80 对象、11 个阶段完成，无渲染错误。打包应用在三视图/日夜/快速移动检查可见前景，并实际导出全部 120 对象/600 笔迹及层序。文档切换主动释放底图/缩略图缓存，真实 15 页画布从 3,600,000 字节到 0，挂载像素保持完整，卸载后缓冲 1×1。
3. **本地 AI。** 保留 SenseVoice 两线程 INT8 非空转策略、事件/截止时间唤醒、热模型与磁盘编译缓存复用及闲置卸载。当前真实 Whisper NPU 三次会话：就绪约 3235/10/3035 ms，中英文切换复用一个 worker；约 30280 ms 测试闲置后退出并重建，测试后恢复默认 1800 秒。PP-OCRv4 CPU 图像/行坐标、服务设备/失败冷却/忙时不释放/取消归还与 ASR 生命周期检查通过。其它设备/驱动兼容及识别准确率仍有边界，后端可回退 CPU。

历史数值只对应各自冻结来源；新的完整流程是当前回归，不拿它与不同 UI/缓存策略的旧样本直接计算百分比。按用户要求，后续候选采用单次 A/B、优先减少计算，不重复求均值。本版不提出电量/续航提升百分比，整机功率没有验证。[历史报告及原始归档边界](performance/README.md)。
