# 0.3.2 发布验证 / Release validation

- TypeScript、生产构建及完整 Prettier 检查通过。Vite 保留已知的大分块提示；本轮没有更换依赖版本。
- 455 项单元测试 / 89 文件通过。23 项 Tesseract/HTTP 生命周期后端测试通过。
- 14 项发布浏览器回归通过：图片下载/提取、逐项资源释放、跨文档页面剪贴板与撤销、空白页粘贴、CPU 四路停止、NPU 混合分行/计时、OCR 搜索/选文、压感映射与 UI 倍率。
- 实机严格 NPU 英文 Best 与中英混合小样本已验证；混合字符结果与 CPU 原型相同，仍有空格遗漏，不代表文档级准确率或速度优势。英文 61 页单次实验及局限另见性能报告，未测量能耗。
- 生成 Windows x64 NSIS 轻量安装器；未运行安装器或此次打包的应用，不重做导致主机不稳定的安装测试。沿用先前升级/修复/降级保护实现，不声称本轮重新验证了实际安装过程。
- 静态检查：版本 0.3.2、14 组模型目录记录、315 个包条目、264 个 dist 文件逐个 SHA256/集合一致；7 个图标尺寸与设计一致；原生预加载、图像导出、PDF worker 及 NPU 后端存在；模型权重不在轻量包中。
- 原有 0.3.1 安装包和五个冻结性能脚本保持不变。私有工作目录、模型、原书图片/识别正文、凭据与本机日志不进入发布源代码或安装包。

安装包和校验清单、源码提交见 Release 随附 `BUILD-INFO.json` / `SHA256SUMS.txt`。原生 Tesseract 的 DAWG/beam 解码及归一化保真、混合模式空格与长期内存压力仍待进一步验证。
