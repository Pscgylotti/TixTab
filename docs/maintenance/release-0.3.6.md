- 首轮浏览器检查 37/40 通过。修正旧导出测试缺失的加页面板确认操作；翻页居中检查等待实际过渡动画完成。定向复测通过，未降低内容保留、取消恢复、居中或手势断言。

- 发布构建包含 Windows 原生 OCR / Speech 和 native Tesseract，版本身份更新到 0.3.6。轻量包不包含神经模型权重；安装包、ASAR、原生组件与源码静态核验结果以随包 BUILD-INFO.json / SHA256SUMS.txt 为准。
