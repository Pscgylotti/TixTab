# 0.3.7 发布验证 / Release validation

- 571 项单元测试 / 122 文件通过，格式检查通过。
- 47 项浏览器发布回归一次通过：首次英文、中文及不支持语言的默认行为，桌面系统语言优先级，手动选择与重载持久化，中英文延迟加载面板；三种展示全屏、触控板/触屏手势、音乐自动翻页；语音进度/取消/波形/尾键与最终文字收取；后台处理、工作空间、Markdown、键盘策略、聊天及真实 PDF 导出 worker 的取消与恢复。
- 语言优先级为已保存手动选择、系统偏好中第一个支持的语言、英文。桌面版通过 preload 的只读参数传入首选语言，避免同步 IPC；自动匹配不写入手动设置。
- 主窗口关闭与 before-quit 时销毁浮动子窗口，覆盖子页面阻止关闭、子窗口已关闭和主窗口关闭后的延迟创建；浮动聊天设置 skipTaskbar。相关退出行为由单元夹具验证，没有在本机运行打包后的 Electron。
- Alt+Tab 已有空白项未确认根因，没有发现对应 TixTab 进程或窗口；截图可能与 Windows/Edge 标签页记录有关。本版本不宣称能清除系统已缓存的切换记录。
- 安装器及打包后的 Electron 不在本机启动；不覆盖既有发布资产，不修改五个冻结性能脚本。生产资源、原生 OCR/Speech 组件、图标、版本身份与轻量模型排除的静态核验，以随包 BUILD-INFO.json / SHA256SUMS.txt 为准。
- 原生模型推理未为 0.3.7 重跑；保留此前验证与限制，包括 Hy-MT2 OpenVINO NPU 本机初始化失败，不宣称新的性能或能耗改善。
