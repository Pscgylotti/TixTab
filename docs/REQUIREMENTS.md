## 继续实现的性能项

- [x] 单页/连续/双页/缩略图共享背景缓存，避免视图来回切换重复绘制。
- [x] 绘制最多两路并行，当前页优先；视区外取消任务，共享请求仍有订阅时保留。
- [x] 已完成笔迹几何与 Path2D 缓存；活动笔划仍实时重绘。
- [x] 自动保存按变更页写入，页码/缩放变化只写元数据。
- [x] 连续页与缩略图 DOM 虚拟化；1000 页混合尺寸 PDF 的首尾跳转、选文、缩放锚点和跨视区排序已验证（不代表所有复杂文档的性能）。
- [x] 高倍率按视区高清瓦片，三种视图共用；512px 网格，每页细节层不超过 600 万像素，平移复用重叠块，快速预览不加载瓦片。
- [x] Texo OpenVINO CPU/GPU/NPU 编码、CPU 缓存解码独立服务，公式画板与区域识别共用低功耗路由，包内权重复用。
- [x] 实验夜间颜色由独立 Worker 处理并缓存，普通/节能档自适应并行与像素预算，原色位图可直接用于夜间处理而不重新解码 PDF。
- [x] 输入期间暂停 PDF.js 后续时间片和排队补绘；隐藏窗口暂停，恢复后继续；节能档减少玻璃背景模糊。
- [x] 0.2.18 支持原生/WASM 切换释放闲置模型、队列内手动释放、免推理翻译保留热模型、原生一次闲置期限取代周期轮询；本机 Texo 两轮模型释放/重载与进程内存记录通过。
- [x] Piper OpenVINO 中英声音的 NPU/GPU/CPU 波形生成、重叠边界、动态 CPU 尾段、共用生命周期与真实 WASM 回退。
- [ ] Piper 发音/韵律人工质量集、OPUS/OCR 更大真实质量样本及实测功耗；现有 CPU 基线继续可用。
- [ ] Texo 更大手写样本集与电池放电/真实功耗测量；三个合成样本不代表准确率或能耗结论。
- [ ] 原生墨迹与当前 Web Canvas 的真笔延迟对比。

不以现有自动化测试替代尚未完成的硬件测量，未完成项继续保留在计划中。

- [x] PP-OCRv4 原生文字识别、重叠分块检测、NPU/GPU 静态识别骨干与 CPU 投影、长行 CPU 回退、共用任务锁/闲置释放；12 个合成区域的三设备结果保存在 benchmarks。

0.2.13 增加按功能/后端的持久 API 配置、公式 HTTP/LLM、加密凭据、连接检查和流式文本；0.2.14 加入桌面无 CORS HTTP 中继与有界按需分块；0.2.15 增加按需模型管理及默认轻量打包；0.2.17 统一 Provider 能力/任务生命周期、任务面板与取消，工作空间管理配色改为组件隔离。使用方式与验证边界见 [后端配置](API-PROVIDERS.md)、[模型管理](MODEL-LIBRARY.md) 和 [任务调度](PROVIDER-TASKS.md)。0.2.20 增加固定应用缓存与浏览器缓存管理；质量样本和硬件功耗等后续项继续保留。
