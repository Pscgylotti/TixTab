## 有限开源调查（2026-10-10）

1. [PDF.js](https://github.com/mozilla/pdf.js)：Apache-2.0；浏览器成熟渲染器，worker 解析、可取消 RenderTask。参考 [官方示例](https://github.com/mozilla/pdf.js/blob/master/docs/contents/examples/index.md) 与 [FAQ](https://github.com/mozilla/pdf.js/wiki/Frequently-Asked-Questions)。基准使用其真实渲染结果做低清首屏和位图缩放；后续已加入按视区高清瓦片。
2. [pdf-lib](https://pdf-lib.js.org/)：MIT；页面嵌入、增删和矢量路径导出。0.2.21 改为复用源页面，保留交互信息；新增标注按原旋转/crop/UserUnit 矩阵输出为 Stamp 外观，仍不声称覆盖所有复杂 PDF 结构。

4. [Excalidraw](https://github.com/excalidraw/excalidraw)：MIT；使用 npm 编辑器与 [官方导出 API](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/api/utils/export)，不嵌远程网站。

6. [Pointer Events 标准](https://www.w3.org/TR/pointerevents2/)：压感范围 0–1，背面擦除 button=5/buttons=32。硬件是否正确映射必须现场测试。
