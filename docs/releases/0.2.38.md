# TixTab 0.2.38 · 键盘快捷键与划词定位 / Keyboard shortcuts and selection placement

## 中文

- 悬浮键盘更紧凑，直接在按键布局中加入 Ctrl、Tab、Esc。先点 Ctrl 再点 A/X/C/V/Z/Y 可全选、剪切、复制、粘贴、撤销或重做，执行后自动松开 Ctrl。输入框保留焦点及选区，键盘输入支持原生撤销；PDF 页面的复制/粘贴继续使用已有的文本、图片和对象剪贴板流程。独立聊天窗口也支持这些快捷键。
- 划词浮窗优先比较选区上下方的可用空间；按实际 PDF 视口计算，避开悬浮键盘和底部工具组。空间不足时缩短面板并允许滚动，保留惯用手方向的水平对齐。

运行 `TixTab-0.2.38-lite-x64.exe`。Windows x64 未签名预览版；可选运行时和模型按需下载。本次不改动模型和推理设备设置。

## English

- Make the keyboard more compact and integrate Ctrl, Tab and Esc into its key rows. Tap Ctrl then A/X/C/V/Z/Y for select all, cut, copy, paste, undo or redo; Ctrl releases after the action. Preserve field focus and selection, record native undo history, and reuse the PDF text/image/object clipboard workflow. Shortcuts also work in the independent chat window.
- Prefer the roomier region above or below selected text, using the actual PDF viewport and excluding the floating keyboard and bottom control groups. Shorten and scroll the panel when space is limited, retaining writing-hand alignment.

Run `TixTab-0.2.38-lite-x64.exe`. Unsigned Windows x64 preview; optional runtimes and models download on demand. Model and inference-device settings are unchanged.
