# TixTab 0.3.0 — Thinking over Screen

触屏与手写笔 PDF 阅读、标注及本地 AI 工作空间的首个可用性/交互优化里程碑。支持 Surface Pen。

## 安装

下载 `TixTab-0.3.0-lite-setup-x64.exe` 并核对 `SHA256SUMS.txt`。安装版支持选择目录、升级已有安装、同版本修复及完成页可选桌面快捷方式。基础 PDF 功能不需要 Node.js/Python；可选本地模型和独立运行时在应用中按需下载。

## 本版重点

- 更紧凑且可收起的工具栏、统一设置控件、中英文与夜间界面；空白纸张、草图/公式退出、长按粘贴和缩略页排序插入线修复。
- 三种视图都可书写和编辑。笔侧键悬浮高亮图片/链接，指向目标变色；轻点交互、拖动框选笔迹，键鼠可用 Alt+拖动。透明选择外框支持移动和剪切复制粘贴。
- 全文搜索、目录、书签、引用/网址/arXiv/邮箱跳转、复制页、可调侧栏与直接跳页。底部页码为键鼠输入框或触屏数字面板。
- “OCR → 解析位图”支持全文/指定页，识别内嵌及插入图片并保存可搜索文字与行坐标；本地优先、可停止/跳过/重扫。索引保存在 `.tixtab`，暂不写入导出 PDF 的隐藏文字层。
- 多层对象组合、增量插入 LaTeX、独立公式撤销/恢复、草稿持久保存；聊天多页/图片附件、隐藏内部指令、当前页上下文及独立窗口。
- 背景 PDF 与前景对象/笔迹分别裁剪和缓存；减少重复文本提取与公式草稿写入，主动回收文档栅格/显示副本。本地 AI 复用编译缓存和热模型，默认闲置 1800 秒卸载。

## 限制

Windows 11 x64，未代码签名；其它硬件、ARM64 和实体笔驱动组合仍需实测。夜间配色、OCR/公式/语音和账号聊天为实验性功能，识别结果需校对。远程接口会接收提交的内容；ChatGPT/API 可用性与额度由对应服务决定。轻量包不分发神经模型；受限网络下下载可能失败。复杂表单、加密/签名 PDF 和可编辑 PDF 标注互操作仍有限，建议同时保存 `.tixtab` 工程与导出 PDF。

性能验证优先减少计算与重复工作，不承诺节电/续航百分比。真实整机耗电未测量。原始实验归档保存在本机，仓库提供报告及哈希清单，见 [性能证据说明](../performance/README.md)。

## English

TixTab 0.3.0 is the first usability and interaction milestone for a touch/pen PDF workspace. Supports Surface Pen.

Download the **lite x64 installer** and verify `SHA256SUMS.txt`. Choose an installation directory, upgrade/repair an existing installation, and optionally add a desktop shortcut. Core PDF features need no separate runtime; optional AI models and managed Python are downloaded in-app.

Highlights: consistent collapsible UI and themes; editable ink/objects in all views; pen-hover interaction highlights and side-button/Alt ink selection; document search/outline/bookmarks and direct page jumps; bitmap OCR indexing with page ranges and line highlights; nested object groups; persistent formula drafts and incremental LaTeX insertion; multi-page/image chat attachments and a detachable assistant.

Rendering optimizations retain image quality, separate background/foreground work, share bounded text caches and retire old rasters. Model/compilation reuse and configurable idle unloading remain enabled. Resource measurements are not battery-life guarantees.

**Windows 11 x64, unsigned.** Recognition, night colors and account chat remain experimental. Check recognized content; keep editable `.tixtab` projects alongside PDF exports. Bitmap OCR metadata is searchable in TixTab projects, not embedded in exported PDFs. Optional weights require downloads and their own licenses. Remote providers receive submitted content and control their usage limits. Other hardware, ARM64, complex forms/encrypted/signed documents and PDF annotation interoperability have limitations.
