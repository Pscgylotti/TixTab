# TixTab 0.3.5 — PDF 对象编辑与翻译 / PDF object editing and translation

## 中文

下载 **TixTab-0.3.5-lite-setup-x64.exe**，可升级已有 Windows 11 x64 安装，并保留工作空间、设置与已下载模型。程序未签名，请核对随附 `SHA256SUMS.txt`。

- **PDF 对象编辑**：合并 `claude/pdf-object-audit`，使用 PDFium 编辑原生文字、图片和路径对象的位置、大小、旋转、翻转及叠放顺序；支持多选、对齐、分布、键盘微调、填充/描边和线宽。拖动预览显示实际对象，每次操作可撤销。文字内容修改和图片替换保留原有编辑入口，并修复部分原生文字拒绝编辑的问题。对象操作当前直接应用并重新保存文档，超大文档可能较慢；尚不支持完整的 Foxit 功能集。
- **便签与草稿纸**：便签工具创建后自动切换到移动工具并选中新便签；关闭按钮收起对应便签，再次点击锚点可打开。修复草稿纸便签定位、文本输入和草稿截图 OCR。橡皮擦及笔尾橡皮可在一次拖动中跨 PDF/草稿纸工作，两侧实时预览，一次撤销恢复；松手、取消或退出草稿模式释放预览缓冲。
- **原图查看器**：下载按钮左侧新增复制；左右两侧的触屏按钮与键盘方向键浏览前后图片，按文档页序跨页并跳过无图页。切图重置缩放，复制与下载保留原图像素和颜色，关闭时取消加载并释放画布。
- **快捷面板与笔触**：右下角改为更多操作图标，包含删除页、清空本页标注、复制页、插入空白页和翻译入口。笔触悬浮预览改为实际落笔半径圆圈；顶部标签与底部工具条隐藏滚动条，保留滚动操作。
- **常驻翻译与 Hy-MT2**：无需先划词即可打开并编辑翻译内容；目标语言旁提供三个最近使用的语言快捷项。新增可选本地 Hy-MT2 1.8B，以及 llama.cpp CPU/Vulkan 和 OpenVINO 后端，复用已有运行环境与模型管理；修复桌面端这两个后端设置的保存校验。

Hy-MT2 权重和运行组件按需下载，不捆绑在轻量安装包中。OpenVINO CPU/GPU 已有本机推理验证，但初始化可能较慢；本机 NPU 初始化未成功，不宣称 NPU 可用或加速。系统模型、硬件与真实文档仍需自行验收。此次未在本机运行安装器或打包后的 Electron，也不把模拟输入作为实体 Surface Pen 验收。

感谢 Anthropic **Claude** 对 PDF 对象编辑实现与审计的贡献；已加入中英文 README 的贡献者名单，与项目维护者及 OpenAI Codex 一同署名。

## English

Download **TixTab-0.3.5-lite-setup-x64.exe** and verify `SHA256SUMS.txt`. Upgrades preserve existing workspaces, settings and downloaded models. Windows 11 x64; unsigned.

- Merge Claude's PDF object editing work: selection, live move/resize/rotate previews, flips, stacking, alignment/distribution, keyboard nudging and fill/stroke controls. Operations are undoable; text content and image replacement retain the existing editor. Object operations currently apply directly and re-save the document; large files may be slow.
- Fix review-note editing/placement, scratch capture and cross-sheet erasing, including pen-tail input, previews, undo/cancel and buffer release.
- Copy original images beside Download; browse with side touch buttons or Left/Right keys across document pages, skipping pages without images. Native pixels/colors are preserved, zoom resets on image changes and closing releases resources.
- Add page quick actions, brush-radius previews, standalone editable translation and three recent target-language shortcuts. Hide overflow scrollbars while retaining scrolling.
- Optional Hy-MT2 1.8B translation via llama.cpp CPU/Vulkan or OpenVINO, sharing existing runtime/model management. Fix desktop persistence of both new provider profiles. Weights download separately; OpenVINO CPU/GPU inference was checked locally, while local NPU initialization failed and is not claimed to work.

Thanks to **Claude by Anthropic**, credited as an AI coding contributor for PDF object editing implementation and auditing alongside the project maintainer and OpenAI Codex. Installer and packaged Electron execution were not rerun on this host; automated/synthetic checks do not replace hardware acceptance.
