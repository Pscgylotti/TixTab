# SurfaceTab 0.2.35 — first public preview / 首个公开预览版

## 中文

- 首次公开发布应用源码与 Windows x64 轻量便携包。
- ChatGPT 助手可切换到独立悬浮窗口；新增根据描述生成 SVG、预览与插入 PDF 对象。
- 拖入图片/SVG 可插为对象；拖入 PDF 可选择新标签页打开、插入全部或指定页面，支持撤销/重做。
- 悬浮键盘新增独立语音模式：中英文、实时波形、SenseVoiceSmall/Whisper small/Windows 引擎，直接写入当前输入框。
- 英文、拼音与 LaTeX 键盘使用错位字母行，ASDF 向右移动，保留 Shift 符号预览与二级大小设置。
- 一键准备独立 Python、通用 OpenVINO 与语音依赖；显示安装阶段，支持取消、重试及复用。
- 统一代码格式，补充持续集成、安装验证、中英文说明和第三方协议。
- 收起后的工具图标合并到工作空间一栏，移除重复标题与低清晰度快速预览开关；调整夜间原色按钮和紧凑划词浮窗。
- 模型下载确认改为居中弹窗，修复对象框选的位置偏移。
- 本地翻译回退选项收进后端设置，减少主浮窗占用；公式后端、设备、多行与常用命令统一收进公式设置。
- Surface Pen 侧键在 PDF 区域打开环形工具菜单，快速切换笔触、移动、选文与对象；已有选词时，中心按钮打开划词操作。
- 轻量包不含模型权重；Huayan 声音数据许可尚未明确，不随本次公开版本分发。应用采用 AGPL-3.0-only，模型各有独立许可。

直接运行 `SurfaceTab-0.2.35-lite-x64.exe`。基础 PDF 功能无需 Python；可选 AI 在设置中下载模型、安装运行时。需联网，驱动、Zotero 和账号另行配置。仅 Intel Windows x64 路径经过验证，ARM/其它设备仍待测试。程序未签名，为实验性预览，请保存重要文档副本。

## English

- First public source release and Windows x64 lite portable.
- Detachable native ChatGPT window and SVG generation, safe preview and insertion as PDF objects.
- Drop images/SVG as objects; choose new tabs or all/selected PDF page insertion, with undo/redo.
- A dedicated voice keyboard mode: Chinese/English, live waveform and SenseVoiceSmall/Whisper small/Windows engines, inserting into the current text field.
- Staggered English/Pinyin/LaTeX letter rows, including a right-shifted ASDF row; Shift previews and secondary size settings retained.
- One-click managed Python, OpenVINO and speech setup with progress, cancellation, retry and reuse.
- Consistent formatting, CI, installation verification, bilingual documentation and third-party notices.
- Compact tools share the workspace row; redundant titles and the fixed low-resolution preview switch are removed. Improved night controls and selection flyout sizing.
- Centered model download confirmation and corrected object marquee positioning.
- Local translation fallback moves into backend settings; formula backend, devices, multiline options and macros share one collapsible settings panel.
- Surface Pen barrel button opens a radial tool menu over the PDF, with a central text-action shortcut when text is selected.
- No neural weights bundled. Huayan voice excluded because its dataset redistribution terms are unclear. App code is AGPL-3.0-only; models have separate terms.

Run `SurfaceTab-0.2.35-lite-x64.exe` directly. Basic PDF features need no Python. Prepare optional AI runtimes/models from Settings. Internet access is needed; drivers, Zotero and accounts are separate. Only Intel Windows x64 is validated; ARM/other devices remain untested. This unsigned experimental preview requires keeping copies of important documents.
