# TixTab 0.2.35 — first public preview / 首个公开预览版

## 中文

- 单页、连续及双页共用编辑层：可直接压感书写、尾擦、框选/移动/缩放/删除及编辑对象，插入对象保持当前模式；修复重启后预览不能写以及双页切换连续时回到第一页。

- 应用标语更新为 Thinking over Screen。
- 可编辑的多行文本框：字号、颜色、粗体、移动/缩放；PDF 区域 Ctrl+V 智能插入图片或文本，输入框保留普通粘贴。
- 模型闲置卸载时间统一可配置，默认 1800 秒；涵盖本地语音、公式、翻译、OCR 与 TTS，保留权重和编译缓存。

- 首次公开发布应用源码与 Windows x64 轻量便携包，正式名称为 TixTab；保留旧版工程、设置与模型缓存兼容。
- 夜间图片保留色相并降至与 PDF 位图一致的亮度；单页/连续/双页和缩略图统一处理，可通过“查看原色”恢复。
- ChatGPT 助手可切换到独立悬浮窗口；新增根据描述生成 SVG、预览与插入 PDF 对象。
- 拖入图片/SVG 可插为对象；拖入 PDF 可选择新标签页打开、插入全部或指定页面，支持撤销/重做。
- 悬浮键盘新增独立语音模式：中英文、实时波形、SenseVoiceSmall/Whisper small/Windows 引擎，直接写入当前输入框。
- 英文、拼音与 LaTeX 键盘使用错位字母行，ASDF 向右移动，保留 Shift 符号预览与二级大小设置。
- 一键准备独立 Python、通用 OpenVINO 与语音依赖；显示安装阶段，支持取消、重试及复用。
- 统一代码格式，补充持续集成、安装验证、中英文说明和第三方协议。
- 收起后的工具图标合并到工作空间一栏，移除重复标题与低清晰度快速预览开关；调整夜间原色按钮和紧凑划词浮窗。
- 模型下载确认改为居中弹窗，修复对象框选的位置偏移。
- 本地翻译回退选项收进后端设置，减少主浮窗占用；公式后端、设备、多行与常用命令统一收进公式设置。
- Surface Pen 侧键在 PDF 区域打开环形工具菜单，快速切换笔触、移动、选文与对象；已有选词时，中心按钮打开划词操作。
- 轻量包不含模型权重；Huayan 声音数据许可尚未明确，不随本次公开版本分发。应用采用 AGPL-3.0-only，模型各有独立许可。

文本框在工程内保持可编辑；导出 PDF 时暂按高分辨率图片嵌入，不生成可搜索文字。

直接运行 `TixTab-0.2.35-lite-x64.exe`。基础 PDF 功能无需 Python；可选 AI 在设置中下载模型、安装运行时。需联网，驱动、Zotero 和账号另行配置。仅 Intel Windows x64 路径经过验证，ARM/其它设备仍待测试。程序未签名，为实验性预览，请保存重要文档副本。

## English

- Shared editing in single, continuous and facing-page views: pressure ink, release-to-erase, object selection/movement/resizing/deletion and editing. Insertion keeps the current view; restarting no longer leaves preview pages uneditable, and switching from facing to continuous preserves the page.

- Tagline updated to Thinking over Screen.
- Editable multiline text boxes with size, color, bold, moving and resizing; Ctrl+V inserts clipboard images or text over the PDF while normal field paste is preserved.
- Configurable model idle unloading, default 1800 seconds, covering local speech, formula, translation, OCR and TTS; weights and compilation caches are kept.

- First public source release and Windows x64 lite portable, named TixTab; legacy projects, preferences and caches remain compatible.
- Imported pictures retain their hues with PDF-style night dimming in all layouts and thumbnails; the original-color switch restores brightness.
- Detachable native ChatGPT window and SVG generation, safe preview and insertion as PDF objects.
- Drop images/SVG as objects; choose new tabs or all/selected PDF page insertion, with undo/redo.
- A dedicated voice keyboard mode: Chinese/English, live waveform and SenseVoiceSmall/Whisper small/Windows engines, inserting into the current text field.
- Staggered English/Pinyin/LaTeX letter rows, including a right-shifted ASDF row; Shift previews and secondary size settings retained.
- One-click managed Python, OpenVINO and speech setup with progress, cancellation, retry and reuse.
- Consistent formatting, CI, installation verification, bilingual documentation and third-party notices.
- Compact tools share the workspace row; redundant titles and the fixed low-resolution preview switch are removed. Improved night controls and selection flyout sizing.
- Centered model download confirmation and corrected object marquee positioning.
- Local translation fallback moves into backend settings; formula backend, devices, multiline options and macros share one collapsible settings panel.
- Surface Pen barrel button opens a radial tool menu over the PDF, with a central text-action shortcut when text is selected.
- No neural weights bundled. Huayan voice excluded because its dataset redistribution terms are unclear. App code is AGPL-3.0-only; models have separate terms.

Text boxes remain editable in projects; PDF export currently embeds high-resolution images rather than searchable text.

Run `TixTab-0.2.35-lite-x64.exe` directly. Basic PDF features need no Python. Prepare optional AI runtimes/models from Settings. Internet access is needed; drivers, Zotero and accounts are separate. Only Intel Windows x64 is validated; ARM/other devices remain untested. This unsigned experimental preview requires keeping copies of important documents.
