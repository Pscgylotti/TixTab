# TixTab 0.3.1 — 文档标签与编辑改进 / Tabs and editing

## 中文

下载 **TixTab-0.3.1-lite-setup-x64.exe**，运行安装器可升级已有安装，保留工作空间、设置和模型。核对随附 `SHA256SUMS.txt`。支持 Windows 11 x64、Surface Pen；程序未代码签名。

- 顶部 PDF 标签支持拖动插入排序，自动保存顺序。触屏长按打开菜单，长按后拖动排序；鼠标右键、Shift+F10 也可打开菜单。提供关闭当前、关闭其它、关闭右侧所有标签；关闭不删除工作空间文档。
- 新增基础原生 PDF 文本/图片编辑：暂存修改、真实 PDF 预览、拖动/缩放位置与大小，应用编辑或导出时生效。修复 Type1 字体编辑后字形偏移的问题。
- 新增区域便签、侧边连接线和审阅批注导出；页面旋转、框选裁剪及拆分支持当前/全部/指定页。
- 优化位图 OCR 内存：先建几何索引，逐项加载、释放专用解码缓存与画布；Tesseract 可选 1/2/4 个并行任务。新增极低内存模式，模型闲置卸载时间独立设置。
- 独立 Python/依赖安装支持镜像和自定义 HTTPS PyPI 源、安装日志，以及关闭后选择后台继续安装。
- 改进紧凑语音键盘、空白页样式与插入/删除小窗口、笔迹选区缩放、非线性粗细调节及固定预览占位。修复 Excalidraw 擦除轨迹偏移；缩略图增加触屏惯性。
- 实验性笔振动开关与强度设置：需要兼容设备、驱动及系统设置；实体笔反馈仍待进一步验证。

原生编辑是基础片段编辑，尚无段落重排和复杂矢量/字体的完整保真；先保存 `.tixtab` 工程。裁剪不是安全涂黑。可选运行时/权重按需下载；本版不宣称 Tesseract GPU/NPU 加速或电池续航提升。更多边界见 [PDF 编辑说明](https://github.com/Pscgylotti/TixTab/blob/v0.3.1/docs/PDF-EDITING.md)。

## English

Download **TixTab-0.3.1-lite-setup-x64.exe** and verify `SHA256SUMS.txt`. Run the installer to upgrade while retaining workspaces, settings and models. Windows 11 x64; supports Surface Pen. Unsigned executable.

- Persistent drag-to-reorder document tabs. Long-press for close/current/other/right actions; hold then drag on touch. Right-click and Shift+F10 are supported. Closing keeps workspace documents.
- Basic native PDF text/image editing with staged changes, actual PDF previews, move/resize controls and apply/export. Fixes edited Type1 glyph offsets.
- Region review notes and PDF review annotations; page rotation, rectangle-based crop and split/extract with page ranges.
- Geometry-only bitmap indexing and per-image decoder/cache release, optional 1/2/4 Tesseract workers, and an extreme memory mode with independently configurable model idle unloading.
- Managed Python setup mirrors, custom HTTPS PyPI sources, installation logs and optional background continuation.
- Compact voice editing keyboard, blank-page styles and nearby popovers, ink selection resizing, nonlinear pen width, thumbnail touch inertia and Excalidraw eraser preview correction.
- Experimental pen haptics toggle/intensity; actual device feedback requires further verification.

Native editing does not provide full paragraph reflow or universal font/vector fidelity. Keep `.tixtab` projects; cropping is not secure redaction. Optional runtimes/models download separately. No Tesseract GPU/NPU acceleration or battery-life improvement is claimed.
