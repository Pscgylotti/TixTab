# TixTab 0.3.2 — OCR、资源与编辑改进 / OCR, resources and editing

## 中文

下载 **TixTab-0.3.2-lite-setup-x64.exe**，运行安装器可升级已有安装，保留工作空间、设置和模型。Windows 11 x64，支持 Surface Pen。程序未代码签名，请核对随附 `SHA256SUMS.txt`。

- “解析位图”增加独立的 **Tesseract · NPU · 实验性** 后端，可选英文 Best/Fast 或 **简体中文 + English · 混合 Best**。使用有界 16 行队列；英文最大 batch 1/2/4，混合模式暂固定单行推理。CPU 负责分行及前后处理，NPU 失败明确报错，不静默 CPU 回退。
- 加固 CPU OCR 停止：取消加载/解码/清理等待，专用扫描 PDF worker 立即退出；保留已完成结果。4 路任务另受 400 万活动输入像素总预算限制，大图减少并发并共享空闲 worker，回收闲置高水位工作区，避免轮流撑大四套 WASM 堆。
- 增加“耗时详情”，查看分行、推理、本次编译和服务处理时间。累计任务时间可能重叠，不等同整批实际耗时；NPU 不保证更快或更省电。
- 截图和原图可保存 PNG；聊天按钮旁的额外工具支持提取当前页、全文或指定页的位图，保存到所选目录。逐张处理、可取消、避免覆盖已有文件。
- 支持跨文档复制/粘贴页面，保留可编辑笔迹、对象、便签和 OCR 元数据；单页源快照、剪贴板及撤销源历史有内存上限。
- 设置增加整体界面倍率 0.5–4.0（现有大小以 2.0 为基准），以及默认线性的分段压感曲线。可添加最多 16 个内部点，拖动、删除及恢复默认；只影响 PDF、公式和草图中的新笔迹。

轻量包不含神经模型权重。NPU 后端需在“本地模型管理”准备本地加速运行时、分行语言包及所选识别模型；混合 Best 单独下载约 12.5 MiB，更新后重启应用/本地服务。混合模式已验证中英合成样本，仍可能漏空格或识别错误；未完成文档级人工精度评测。原 CPU Tesseract 仍为默认。详见 [OCR 说明](https://github.com/Pscgylotti/TixTab/blob/v0.3.2/docs/TESSERACT-OPENVINO.md)。

## English

Download **TixTab-0.3.2-lite-setup-x64.exe** and verify `SHA256SUMS.txt`. The installer upgrades existing installations while preserving workspaces, settings and models. Windows 11 x64; supports Surface Pen. Unsigned executable.

- Optional experimental queued Tesseract NPU backend for bitmap analysis: English Best/Fast and mixed Simplified Chinese/English Best. A bounded 16-line queue; English maximum batches 1/2/4, mixed mode currently single-line inference. CPU handles layout and pre/postprocessing. NPU errors are explicit, without silent CPU recognition fallback.
- Hardened CPU OCR cancellation and dedicated scan-worker teardown, keeping completed results. A 4-million-active-input-pixel budget reduces concurrency for large scans. Idle OCR owners are shared and oversized idle working sets retired instead of growing four separate WASM heaps across decode lanes.
- Timing details for layout, inference, compilation and service processing. Task times may overlap and are not batch wall time. NPU speedups or battery savings are not guaranteed.
- Save captures/original images as PNG; Extra tools can extract bitmap images from the current document to a selected folder, with page ranges, cancellation, sequential resource release and no overwrite.
- Cross-document page copy/paste preserves editable foreground content, review notes and OCR metadata, with bounded page snapshots, clipboard and source undo history.
- Overall UI scale 0.5–4.0, with 2.0 matching the existing size; a piecewise pressure curve with up to 16 internal control points. New PDF/formula/sketch strokes use the curve; existing strokes stay unchanged.

The lite build excludes neural weights. Prepare the local acceleration runtime, layout language pack and selected OCR model in the model library; mixed Best is a separate approximately 12.5 MiB download. Restart the updated application/local service. Mixed synthetic samples were validated, but spacing errors remain and document-level accuracy is not established. The CPU Tesseract default is unchanged. Installation itself was not rerun on this host.

AGPL-3.0-only application; third-party code/models retain their licenses. [Corresponding source](https://github.com/Pscgylotti/TixTab/tree/v0.3.2).
