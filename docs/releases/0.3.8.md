# TixTab 0.3.8 — 英文界面补全 / English interface coverage

## 中文

下载 **TixTab-0.3.8-lite-setup-x64.exe**（Windows 11 x64）。安装包未签名，可用随附 `SHA256SUMS.txt` 校验。升级保留工作空间、设置和已下载模型。

- 补全草稿、文档矫正、五线谱识别与播放器、图片裁剪和透明色、PDF 元素编辑、语音状态等英文界面与提示。
- “草稿纸”统一显示为 **Draft**，自动生成的名称显示为 **Draft 1** 等。已有默认名称随界面语言切换，手动命名与文档内容保持原样。
- 补全纯文本 / Markdown 模式、预览及部分原生文件选择窗口的英文说明。
- 加入翻译覆盖检查及英文操作回归，避免新增界面词条遗漏英文。

轻量包不包含神经模型权重。本轮通过自动化测试、生产构建和安装包静态校验验证；未启动安装器或打包后的 Electron，未重新运行原生模型推理。此前模型和系统兼容性限制保留。

## English

Download **TixTab-0.3.8-lite-setup-x64.exe** for Windows 11 x64. The installer is unsigned; verify it with `SHA256SUMS.txt`. Upgrades retain workspaces, settings and downloaded models.

- Complete English controls and messages for Draft, document correction, music recognition/playback, image cropping/transparency, PDF object editing and speech status.
- Use **Draft**, **Draft 1**, etc. for generated labels. Existing default names follow the interface language; custom names and document content remain unchanged.
- Complete plain text / Markdown controls, previews and the original PDF selection dialog.
- Add translation coverage checks and English interaction regressions.

Neural weights download separately. Validation used automated tests, a production build and static package verification. The installer and packaged Electron were not launched; native model inference was not rerun. Previous model and system compatibility limitations remain.
