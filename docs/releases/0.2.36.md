# TixTab 0.2.36 · 阅读与聊天改进 / Reading and chat improvements

## 中文

- 聊天助手可选择 OpenAI 兼容的 LLM API，配置接口、模型、Key、自定义请求头、超时与流式回答。继续支持现有 ChatGPT 账号方式，二者的历史记录分开保存。
- API 模式支持页面文字/图片附件、原 PDF 总结与 SVG 生成。原 PDF 默认提取文字；支持文件输入的模型可在高级设置中改为发送文件。文字最多 100,000 字符，超出时明确标注截断；文件最多 16 MB。扫描图像请使用页面图片或 OCR。
- 图层“上移一层/下移一层”菜单保持展开，便于连续调整。
- 打开 PDF 或工程时替换未修改的默认空白文档；已写入内容、重命名或调整纸张的文档仍保留。导入失败时保留原文档。
- 本地翻译模型已常驻且语言方向匹配时，第一次点击划词浮窗的“翻译”即可运行。点击页面空白且没有选中文字后自动关闭浮窗；操作翻译、朗读和设置时保留选区。

聊天 API 使用所配置服务的独立 API 额度。桌面版通过系统加密保存凭据；浏览器预览的凭据只在本次会话有效。仅兼容 Chat Completions 协议；图片/PDF 支持由模型决定，不自动切换计费方式。测试使用受控本地服务，没有调用付费 API。运行 `TixTab-0.2.36-lite-x64.exe`；可选模型及运行时仍按需下载。此版为未签名 Windows x64 预览。

## English

- Choose an OpenAI-compatible LLM API in the reading assistant, with endpoint, model, key, custom headers, timeout and streaming controls. ChatGPT account mode remains available; their histories are separate.
- API mode supports page text/images, original-PDF summaries and SVG generation. PDF input defaults to extracted text; enable file input only for a model that supports it. Text is limited to 100,000 characters with explicit truncation notices; files are limited to 16 MB. Use page images or OCR for scans.
- One-layer stacking controls stay open for repeated adjustments.
- Opening a PDF/project replaces the untouched default document. Modified or renamed notes and failed imports are preserved.
- A resident local translation model runs on the first Translate click when its language direction matches. Clicking empty page space without a text selection dismisses the flyout; its controls preserve the selection.

API usage is billed separately by the configured service. Desktop credentials use OS encryption; browser-preview credentials are session-only. Chat Completions is the supported protocol; image/PDF capabilities depend on the model. Controlled local services were used for testing, without paid API calls. Run `TixTab-0.2.36-lite-x64.exe`; optional models/runtimes download on demand. This is an unsigned Windows x64 preview.
