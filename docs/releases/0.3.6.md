# TixTab 0.3.6 — 展示全屏与原生语音 / Presentation and native speech

## 中文

下载 **TixTab-0.3.6-lite-setup-x64.exe**。Windows 11 x64，支持升级已有安装并保留工作空间、设置和已下载模型。安装包未签名，可使用随附 `SHA256SUMS.txt` 校验。

- **展示全屏**：三种视图可隐藏其它界面并居中展示，保留缩放和五线谱自动翻页；双击退出并恢复编辑视图。单页/双页支持触屏与触控板双指左右滑动翻页，惯性尾段不会连续翻过多页。放大后左右滑动用于平移，连续视图保留滚动。
- **Windows 原生语音**：新增可选 Windows AI Speech 本地实验后端与 Windows SDK Speech 后端，显示实际麦克风音量波形。修复首次系统模型加载过早超时、持续听写阻塞结果读取/停止的问题，增加启动阶段与进度提示。停止听写关闭本次采集和识别，模型按设置的空闲时间保留并卸载，修改设置会同步更新计时。
- **Surface Pen 尾键助手**：设置中可选择启用，仅在 TixTab 前台接管；单击打开助手并开始/结束听写，双击结束听写并发送，发送前收取最后一句。识别失败时保留文字，不自动发送。
- **后台进度**：下载和文档处理可收起并继续执行，由小型浮窗查看进度、重新打开或取消；任务结果归属原文档，避免切换后写入其它文档。
- **界面与文本**：未编辑的空白文档不加入工作空间，分组选择按钮避免图标重叠；悬浮键盘收到实体键盘输入后隐藏；修复 Markdown 删除线。

轻量包不包含神经模型权重。Windows AI Speech 仍为实验接口，需要兼容的系统、硬件、应用组件身份与系统模型，模型由 Windows 管理，可能需要通过 Windows Update 下载；SDK Speech 可能联网。首次 NPU 编译在本机实测约 6 分 40 秒，缓存后的加载约 7 秒，此数据仅代表本机测试，不是跨设备性能承诺。尾键依赖设备向应用提供对应快捷键事件，自动化输入不替代实体笔验收。

本轮完成原生语音加载、停止、真实音量计和模型驻留的本机检查，以及自动化回归、安装包静态校验；未运行本机安装器或打包后的 Electron。保留此前 Hy-MT2 OpenVINO NPU 初始化失败的限制，不宣称该翻译后端已支持本机 NPU。

## English

Download **TixTab-0.3.6-lite-setup-x64.exe** for Windows 11 x64. Upgrades retain workspaces, settings and downloaded models. The installer is unsigned; verify `SHA256SUMS.txt`.

- Presentation fullscreen for all three layouts, centered fitting, zoom, score auto-turning, double-click exit and editor-view restoration. Touchscreen and horizontal trackpad gestures turn single pages/spreads once per gesture; magnified pages retain panning and continuous mode retains scrolling.
- Optional experimental local Windows AI Speech and Windows SDK Speech, with real microphone level meters. Fix cold-start timeouts and blocking continuous-recognition startup, report load stages/progress, and keep idle models for the configured unload interval while ending each capture session.
- Opt-in foreground Surface Pen tail assistant: single-click starts/stops dictation; double-click stops and sends after draining the final phrase. Recognition failures retain text without automatic sending.
- Background downloads/processing with a compact progress dock and document-owned results. Hide the floating keyboard on physical input, omit untouched blank workspace documents, improve grouping controls and fix Markdown strikethrough.

Neural weights download separately. Windows AI Speech requires compatible Windows/hardware, component identity and system models; first compilation may take minutes. SDK Speech may use online services. Local smoke measurements do not establish cross-device performance or physical pen acceptance. Installer and packaged Electron execution were not rerun. The earlier local Hy-MT2 OpenVINO NPU initialization limitation remains.
