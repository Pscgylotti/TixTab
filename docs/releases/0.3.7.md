# TixTab 0.3.7 — 系统语言与退出清理 / System language and window cleanup

## 中文

下载 **TixTab-0.3.7-lite-setup-x64.exe**（Windows 11 x64）。安装包未签名，可用随附 `SHA256SUMS.txt` 校验；升级保留工作空间、设置和已下载模型。

- **默认语言**：首次启动按系统首选语言顺序匹配中文或英文，未匹配时使用英文。桌面版读取 Windows 系统首选语言，浏览器版使用浏览器语言偏好。
- **保留手动选择**：已经在设置中选择的界面语言继续优先使用；自动匹配不会覆盖已有选择，也不会改动文档内容。
- **窗口退出清理**：关闭编辑器主窗口时销毁浮动子窗口并退出；退出时绕过子窗口可能阻止关闭的页面处理。浮动聊天窗口不再单独显示任务栏项。

Alt+Tab 中已存在的空白切换项尚未确认根因，排查时未发现对应 TixTab 进程或窗口；可能与 Windows/Edge 标签页记录有关。本版本加强应用窗口退出清理，不宣称能清除 Windows 已缓存的切换记录。

轻量包不包含神经模型权重。保留 0.3.6 的原生语音、模型驻留与尾键功能及其限制。本轮验证包含自动化回归、生产构建和安装包静态校验；未启动安装器或打包后的 Electron，未重新运行本机原生模型推理。

## English

Download **TixTab-0.3.7-lite-setup-x64.exe** for Windows 11 x64. The installer is unsigned; verify `SHA256SUMS.txt`. Upgrades retain workspaces, settings and downloaded models.

- First launch selects Chinese or English in system preference order, falling back to English. The desktop app reads Windows language preferences; browser builds use browser preferences.
- Saved manual language choices take priority. Automatic selection leaves document content unchanged.
- Closing the editor destroys auxiliary windows and quits the app, even if a child page would block closing. Floating chat windows no longer get a separate taskbar entry.

The reported blank Alt+Tab entries have not been conclusively attributed to the app; no corresponding TixTab process/window was found. Windows/Edge tab records remain a possible cause. This release improves application window cleanup and does not claim to purge cached Windows switcher entries.

Neural weights download separately. Native speech and other model limitations from 0.3.6 remain. This release was checked through automated regressions, production builds and static package verification. The installer and packaged Electron were not launched; native model inference was not rerun.
