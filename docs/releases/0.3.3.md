# TixTab 0.3.3 — 剪贴板与连续批注 / Clipboard and sequential review

## 中文

下载 **TixTab-0.3.3-lite-setup-x64.exe**，运行安装器可升级已有安装，保留工作空间、设置与模型。Windows 11 x64，支持 Surface Pen。程序未代码签名，请核对随附 `SHA256SUMS.txt`。

- 新增带预览的会话剪贴板历史：文本、图片、可编辑草图/公式/文本框及笔迹，点击直接粘贴。普通模式数据预算 **128 MiB**，极低内存模式 **32 MiB**，不限制条数，超额淘汰最旧项；预览分页、载荷按需读取。可暂停、删除和清空，历史不保存到磁盘，不导入先前 Windows Win+V 内容。
- 修复 Alt 框选笔迹后的复制/剪切操作条被 PDF 拦截点击；增加复制成功提示与异步防重复提交。撤销、恢复和剪贴板入口移至工具栏最左侧，折叠时也保留。
- 左侧页面多选：键盘 Shift+方向键扩选、回车/空格切换，鼠标与触屏拖选。多选时导航改为全选/全不选/反选；退出恢复。支持跨文档整批复制粘贴，保留页面尺寸、可编辑笔迹、对象、便签和 OCR 信息，整批可撤销；长文档保留缩略图虚拟化。
- 工作空间新增**文件夹连续批注**：递归索引 PDF，默认打开第一份，所有文件归入一个标签。按需读取文件并保存各自编辑进度；浮窗支持上一份/下一份、序号跳转、文件名搜索，以及逐份导出已编辑 PDF。浮窗缩至 270 CSS px，可拖出 PDF 区域；导出可取消，不覆盖原文件或已有同名输出。
- 应用改为单实例，再次启动聚焦已有窗口；移除 Alt 触发的默认桌面菜单，保留应用内快捷键与框选操作。

连续批注目前每份源 PDF 上限 256 MiB、每个文件夹索引最多 10,000 份 PDF；切换文件保留已保存批注，撤销历史在文件切换时重置。原始 PDF 不会被自动写回，批量导出选择单独目录，子目录文件名会展平并处理重名。独立 `.tixtab` 工程只包含当前文件，不包含整个文件夹。剪贴板记录可能含敏感文本或图片，请按需暂停/清空；预算约束的是记录数据，不是整个应用进程的内存上限。

轻量包不含神经模型权重，按需在本地模型管理下载。此前实验性 NPU/中英混合 OCR、设备兼容性与识别精度限制不变。本轮通过单元测试、浏览器交互回归和安装包静态检查；未在本机再次执行安装器或打包后的应用。

## English

Download **TixTab-0.3.3-lite-setup-x64.exe** and verify `SHA256SUMS.txt`. The installer upgrades existing installations while preserving workspaces, settings and models. Windows 11 x64; supports Surface Pen. Unsigned executable.

- Preview and paste session clipboard history for text, images, editable sketches/formulas/text boxes and ink. **128 MiB** data budget, **32 MiB** in minimal-memory mode, with no item-count limit and oldest-entry eviction. Paged previews and on-demand payloads; pause, delete and clear controls. History is not persisted or imported from previous Windows Win+V entries.
- Fixed ink Copy/Cut toolbar clicks intercepted by the PDF surface after Alt selection, with copy confirmation and duplicate-operation guards. Undo, Redo and clipboard controls are at the left, including collapsed layouts.
- Multi-page sidebar selection with Shift+arrows, Enter/Space and mouse/touch dragging; select all/none/invert replaces normal navigation while selecting. Copy/paste multiple pages across documents as one undoable batch, retaining dimensions, editable foreground content, review notes and OCR metadata. Long lists remain virtualized.
- Sequential folder review keeps all PDFs in one tab, indexes recursively and reads files on demand. Individual edits and reading positions are retained. A 270 CSS px floating navigator moves across the application window, with previous/next, numeric jump, filename search and sequential export of edited PDFs. Export supports cancellation and never overwrites originals or existing outputs.
- Single application instance: reopening focuses the existing window. Alt no longer opens the default desktop menu; in-app shortcuts and ink selection remain available.

Folder review currently limits each source PDF to 256 MiB and each folder index to 10,000 PDFs. Switching files preserves saved edits and resets per-file undo history. Originals are not written back automatically. Export uses a chosen output folder, flattening subdirectory filenames and resolving collisions. A standalone `.tixtab` project contains the current file, not the entire folder. Clipboard records may contain sensitive information; pause or clear them as needed. Its budget measures stored history data, not total application memory.

The lite build excludes neural model weights; download them as needed. Existing experimental NPU/mixed OCR accuracy and device compatibility limitations remain. Unit tests, browser interaction regressions and static package checks were completed; the installer and packaged application were not rerun on this host.
