# TixTab 0.3.10 — 拍照、触控与跟谱交互 / Camera, touch and score interaction

## 中文

下载 **TixTab-0.3.10-lite-setup-x64.exe**（Windows 11 x64）。升级保留工作空间、设置和已下载模型。安装包未签名，可使用随附 `SHA256SUMS.txt` 校验。

- **拍照**：附加工具新增摄像头入口，支持前后及外接摄像头切换。横竖屏调整采集偏好，取景框按实际视频比例显示，修复竖屏出现大片黑边的问题。拍照后可旋转、镜像、裁剪，复制图片或插入当前 PDF 页；关闭或切换文档时释放摄像头。
- **裁剪**：框内拖动移动选区，边缘和四角调整大小，框外拖动重新框选，单击保留当前选区。支持鼠标、手写笔和触摸；图片边界限制选区移动，取消手势恢复原选区。
- **触控模式**：设置新增默认关闭的开关。开启后单指可使用当前书写、橡皮及对象工具，双指仍用于移动和缩放；切换为双指操作时取消尚未完成的单指编辑。
- **播放器与跟谱**：三种展示全屏视图都可点击谱面定位播放位置；连续展示按当前谱行平滑滚动，避免整页跳动。修复高幅值音频包直接触发停止的路径，保留正常低音量输入；改进异步定位请求和失败诊断信息。
- **工作空间与夜间显示**：重命名与删除确认显示在所点按钮旁，明确当前操作对象，适配窄屏并保留键盘焦点。修复夜间空白纸张叠加旧纹理的问题。

轻量包不含神经模型权重，可选模型与后端按需下载。跟谱仍为实验功能；本次高幅值输入修复不代表所有大音量或设备断连问题均已解决。摄像头、触摸和音频接口的浏览器验证使用模拟输入，实体设备兼容性仍需实际使用确认；发布检查未运行安装器或打包后的应用。

## English

Download **TixTab-0.3.10-lite-setup-x64.exe** for Windows 11 x64. Upgrades retain workspaces, settings and downloaded models. The installer is unsigned; verify it with `SHA256SUMS.txt`.

- Add a camera tool with front/rear/external camera selection, orientation-aware capture preferences and a preview sized to the actual video aspect ratio. Rotate, mirror or crop a photo, then copy it or insert it on the current PDF page. Closing or switching documents releases the camera.
- Move crop selections by dragging inside, resize from edges/corners, and draw a new selection outside. Clicking preserves the selection. Support mouse, pen and touch, constrain movement to image bounds and restore the selection if a gesture is canceled.
- Add an optional touch mode, off by default. Use the current tool with one finger and navigate with two; starting a two-finger gesture cancels the tentative edit.
- Seek from the score in all three presentation layouts. Continuous presentation smoothly reveals the current system instead of snapping whole pages. Handle high-amplitude PCM without rejecting the following session, preserve quiet input, and improve asynchronous seeking and failure diagnostics.
- Show workspace rename/delete popovers beside the clicked control, with a clear target, narrow-window positioning and keyboard focus handling. Fix duplicate legacy patterns on blank paper at night.

Optional models and runtimes download separately. Score following remains experimental; the loud-input fix addresses one known failure path. Browser tests use simulated camera, touch and audio interfaces, not hardware certification. The installer and packaged application were not launched during release validation.
