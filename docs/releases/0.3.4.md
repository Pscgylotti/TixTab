# TixTab 0.3.4 — PDFium、草稿纸与本地文档工具 / PDFium, scratch paper and local tools

## 中文

下载 **TixTab-0.3.4-lite-setup-x64.exe**，可升级已有安装并保留工作空间、设置和已下载模型。Windows 11 x64；程序未签名，请核对随附 `SHA256SUMS.txt`。

- **PDFium WASM 完全替代 PDF.js**：本地引擎常驻复用，关闭文档释放句柄；迁移页面渲染、缩略图、文字/链接/目录、表单显示、图片索引及提取。修复整页扫描图缩放黑屏、阅读位置回到页顶、竖排文字区域和 PDF 元素暂存预览问题。人工验收见 [PDFium 检查清单](../PDFIUM-ACCEPTANCE.md)。
- **草稿纸**：最多十张独立背景，分开平移缩放，与原 PDF 跨边界书写；可从缩略图拖入独立页面快照、调整图层、隐藏原 PDF、修改背景。草稿与视图状态随工作空间保存，草稿不进入 PDF 导出。页面快照禁止复制/剪切，普通对象可跨两层复制粘贴。改善连续页面衔接、边缘阴影和夜间显示。
- **工作空间**：文档拖入分组，卡片保存第一页预览，旧档缺少预览时留空；连续批注组显示文件份数与进度，首次打开下一份继承视图模式。标签支持定位原文件所在文件夹，紧凑布局修复遮挡和左侧控制位置。
- **文本与图片**：Markdown/纯文本切换和夜间预览；图片透明色取样与 RGB 容差；四边独立拉伸、四角等比缩放、顺/逆时针旋转 90°、矩形裁剪与原图恢复。修复裁剪后再拉伸仅选框变化的问题，三种视图、缩略图、截图和 PDF 导出保持一致。
- **文档矫正**：本地扫描倾斜纠正与 UVDoc 透视/曲面矫正，支持当前页、全文、指定页和指定图片；先预览再应用。UVDoc 复用现有 OpenVINO 环境，可选 CPU/GPU/NPU，不兼容时说明原因或回退。逐张处理，子进程结束后释放模型。
- **乐谱工具**：默认 Audiveris，可选 homr，识别结果附在页面并保存到工程。浮动播放器默认钢琴，可选择合成音色；BPM 刻度滑条支持滚轮每格 1、Shift+滚轮每格 5，范围 20–400。支持点击谱面定位、自动翻页、音符 MIDI 音高/时值修正和 MIDI 导出。
- **homr 播放定位**：符号坐标换算回原页，并吸附到附近检测音符头；通过 MusicXML note ID 保留和弦/声部重排后的对应关系。竖线停在当前起拍音符，跨行延音保留后续位置。**旧 homr 结果请重新识别**。少数 attention 估计位置仍可能有偏差。
- **OCR 与手写**：可选原生 C++ Tesseract CPU 后端；Windows AI OCR 组件入口与身份注册诊断；位图索引避免提前解码全文。改进小尺度轨迹采样、粗笔触轮廓、高倍率实时笔迹、独立笔宽记忆和带压感的橡皮预览。Alt 键鼠交互与笔侧键框选保持一致。

轻量包不含可下载神经模型或 Audiveris/homr 组件。首次使用相应功能需下载本地组件；homr 因 Python 版本要求使用兼容的按需环境。声音输入翻页为单旋律音高跟随实验，不能保证复调演奏准确对齐。Windows AI OCR 取决于 Windows 版本、NPU、系统模型与应用身份；NPU OCR 原型仍有精度/设备限制，未宣称比 WASM 更快，C++ NPU 原型未捆绑。合成音色不是外部 SoundFont 加载器。

升级不自动写回原 PDF。草稿和可编辑信息保存在工作空间/工程；导出结果请用另一查看器核对。构建通过自动测试与安装包静态校验，本机未执行安装器或成品 Electron，不把模拟输入当作 Surface Pen 硬件验收。

## English

Download **TixTab-0.3.4-lite-setup-x64.exe** and verify `SHA256SUMS.txt`. Supports upgrading existing Windows 11 x64 installations while retaining workspaces, settings and downloaded models. Unsigned executable.

- PDFium WASM replaces PDF.js completely, including rendering, thumbnails, text/navigation, form display and bitmap extraction. Fixes scan-page zoom transitions, reading-position restoration, rotated text regions and staged PDF-edit previews.
- Independent scratch papers, detached page snapshots, separate pan/zoom, cross-boundary handwriting, saved per-tab state and night rendering. Scratch content stays in projects and is excluded from PDF export.
- Workspace drag-to-group, persisted first-page previews, sequential-review group metadata, view-mode inheritance and compact-header fixes.
- Markdown text boxes with night previews; image color keys, independent edge stretching, proportional corner resizing, 90° rotation and reversible cropping. Cropped images now stretch correctly in all three layouts and PDF export.
- Local deskew and UVDoc document correction, with preview/apply, selected bitmap and page ranges. UVDoc reuses the OpenVINO environment and offers CPU/GPU/NPU where compatible.
- Audiveris/homr score recognition, page-attached results, local synthesized instruments, draggable BPM control with wheel adjustment, score seeking, automatic page turns, note correction and MIDI export.
- homr cursor locations now use symbol geometry and MusicXML note identities, including chord reordering and tied continuations. **Re-recognize existing homr results** to obtain new positions. Attention-only locations may still be approximate.
- Native C++ Tesseract CPU option, Windows AI OCR component diagnostics, bitmap-index memory improvements and pen sampling/rendering/eraser refinements.

Optional models and Audiveris/homr components download separately. homr uses a compatible on-demand Python environment. Microphone following is an experimental monophonic pitch matcher. Windows AI OCR depends on compatible Windows, hardware, models and identity registration. Experimental NPU recognition retains accuracy/device limitations; no speed advantage over WASM is claimed, and the C++ NPU prototype is not bundled. Instruments use local synthesis, not external SoundFont loading.

Original PDFs are not overwritten automatically. Verify exports in another viewer. Automated tests and static package checks do not replace installer, actual pen-hardware or real-document acceptance.

AGPL-3.0-only application; third-party code/models retain their licenses. [Corresponding source](https://github.com/Pscgylotti/TixTab/tree/v0.3.4).
