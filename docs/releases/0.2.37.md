# TixTab 0.2.37 · 语音加载与渲染恢复 / Speech loading and render recovery

## 中文

- 修复 Whisper NPU 编译缓存反复被清理的问题：本机完整缓存约 850 MiB，超过原 768 MiB 目标；调整为 2 GiB，继续复用既有缓存。独立进程复测模型加载约 4 秒，之前重复加载约 44–51 秒。时间不含 Python 启动、校验和麦克风初始化，不代表所有设备。
- 常驻语音模型直接复用，避免每次扫描全部模型。取消已加载的录音后停止采集、丢弃待返回文字，排空后保留模型；加载期间取消仍终止进程。默认闲置卸载时间保持 1800 秒。
- 修复丢失触摸/笔松手事件导致全部 PDF 页面持续等待的问题；停止输入后自动恢复，持续书写时继续让出渲染资源。
- 修复初始窗口可见性查询晚到而覆盖恢复事件的问题。卡住的页面加载/绘制加入超时保护，取消可立即释放队列，避免阻塞其它文档。

运行 `TixTab-0.2.37-lite-x64.exe`。Windows x64 未签名预览版；模型和运行时按需下载。首次缺少缓存、清理缓存或更新驱动/运行时后仍可能编译。本次没有测量功耗、续航或真实笔延迟。

## English

- Fix repeated Whisper NPU compilation caused by pruning required cache blobs. The measured working set is about 850 MiB, exceeding the previous 768 MiB target; the target is now 2 GiB and existing caches are retained. Fresh-process model loading measured about 4 seconds versus 44–51 seconds before, excluding Python startup, verification and microphone initialization.
- Reuse resident speech workers without scanning every installed model. Cancelling a loaded recording stops capture, discards pending text, and retains the model after draining; cancelling during loading still terminates the worker. Idle unloading remains 1800 seconds by default.
- Recover PDF rendering after missing touch/pen release events, while continuing to defer work during active handwriting.
- Ignore stale initial visibility snapshots after newer window events. Bound stalled render stages and release cancelled queue slots immediately so other documents can continue.

Run `TixTab-0.2.37-lite-x64.exe`. Unsigned Windows x64 preview; optional models/runtimes download on demand. Missing/cleared caches and driver/runtime updates can still require compilation. No new power, battery-life or physical-pen latency measurements are claimed.
