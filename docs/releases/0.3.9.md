# TixTab 0.3.9 — 乐谱跟随、文档矫正与 PDF 关联 / Score following, correction and PDF projects

## 中文

下载 **TixTab-0.3.9-lite-setup-x64.exe**（Windows 11 x64）。升级保留工作空间、设置和已下载模型。安装包未签名，可使用随附 `SHA256SUMS.txt` 校验。

- **乐谱识别与跟随**：加入 Copista 28M 后端，修复分类表缺失；接入 Matchmaker 全谱 HMM 定位与 OLTW 连续跟随，停奏保持位置，跳段通过乐句证据确认，减少相似段落之间反复跳转。缓存参考乐谱，重复启动复用，按设置闲置卸载；停止跟随释放麦克风和实时分析。
- **播放器**：支持 Windows 本机 MIDI 合成器与 MIDI 输出端口、可选音色。折叠时保留播放和声音跟随按钮，全屏时移到右上角；打开状态、BPM、音量、音色、位置等随工程保存，重新打开不自动播放或录音。双页播放完右页后再前进两页。
- **文档矫正**：增加倾斜扫描、证件/透视照片、书页弧度和褶皱处理方式，包含无需模型的几何方法、DocAligner 和 UVDoc。支持四角/网格手动调整、旋转、比例、阴影均衡及预览比较；复用已有 Python 环境。结果可撤销，并保存在工程中。
- **PDF 与工程关联**：从 Windows 打开 PDF 时，查找工作空间中的关联工程；无匹配则新建，唯一匹配直接打开，多个匹配展示封面、页数及创建/修改时间供选择。导入 `.tixtab` 保存独立工作空间副本，PDF 编辑不会自动覆盖原文件。
- **安装与稳定性**：安装器新增 PDF 关联选项，默认不勾选；勾选注册打开方式，并在 Windows 默认应用设置中确认。修复 Review note 的对象选择/删除、模型目录校验，以及附加工具加载失败导致整个界面空白的问题。

轻量包不含神经模型权重；可选后端与模型按需下载。跟谱仍为实验功能：识谱错误、踏板、混响和重复乐句会影响定位，不能保证逐音准确或固定延迟。自动化验证不等于实体手写笔、所有音源或麦克风实测。本轮不运行安装器或打包后的 Electron；既有 Windows AI、NPU 与模型兼容限制保留。

## English

Download **TixTab-0.3.9-lite-setup-x64.exe** for Windows 11 x64. Upgrades retain workspaces, settings and downloaded models. The installer is unsigned; verify it with `SHA256SUMS.txt`.

- Add Copista 28M recognition and fix missing taxonomy assets. Integrate Matchmaker global HMM positioning and OLTW following, hold position during pauses, verify distant jumps with phrase evidence, and reuse cached score references until the configured idle timeout. Stopping releases live microphone analysis.
- Support Windows MIDI synthesizers/output ports and instrument selection. Keep Play/Follow audio controls when collapsed or in fullscreen. Save player preferences with projects without resuming playback or recording automatically. Two-page playback advances after the right page finishes.
- Expand document correction with deskew, ID-card/perspective corners, curved/creased page flattening, DocAligner, UVDoc and model-free geometry. Add manual corners/mesh, rotation, aspect ratio, shadow balancing and before/after previews, reusing existing Python environments.
- Opening a PDF from Windows finds associated workspace projects: create when none match, restore a unique match, or choose among covers, page counts and timestamps. Imported projects become independent workspace copies; editing does not overwrite the original PDF.
- Add an unchecked installer option for PDF association, followed by Windows default-app confirmation. Fix Review note selection/deletion, model catalog validation, and whole-window blank screens caused by optional-tool loading failures.

Optional models and runtimes download separately. Score following remains experimental; recognition errors, repeats, sustain and room acoustics can affect positioning. Automated checks are not hardware certification. The installer and packaged Electron were not launched during this release; existing Windows AI/NPU compatibility limits remain.
