# 文档搜索与导航

- 左栏切换页面、全文搜索、目录、书签；Ctrl+F 打开搜索，Enter/Shift+Enter 切换结果。
- 搜索原 PDF 文字层，以及文本框、公式源码和组合内文字。扫描图片/手写不自动 OCR。
- 结果按可视范围挂载，每行 60px，显示两行带省略号的上下文，禁用横向滚动。悬浮/聚焦查看相邻行上下文，列表与浮层均高亮关键词；长上下文可滚动，超长片段限命中前后各 1000 字符。最多 2000 个结果，每页最多 200 个匹配。
- 同一 PDF 的文本请求共享，最多缓存 128 页，并以约 8MB 文本/结构估算限制保留量。220ms 输入延迟、逐页顺序处理并让出执行，切换查询/面板可取消。单纯修改笔迹不重启搜索，文字对象或页结构改变会更新结果。
- 目录使用 PDF 自带大纲，按源页定位，不自动猜测章节。书签跟随工程页面 ID，支持排序、工作区恢复、工程保存和 PDF 导出；删除页后隐藏，撤销恢复后可再次显示。
- 移动工具下点击 PDF 引用/链接与识别的网址、邮箱、`arXiv:` 编号，内部跳转支持返回/前进。编号识别含新旧格式与版本后缀，打开 arxiv.org/abs；邮箱交给默认邮件应用，不自动发送。跨行同一链接按行联合高亮，链接框不继承普通按钮的最小高度。正文引用须已有链接目标，不根据任意编号猜测。外部仅允许 HTTP/HTTPS/mailto，交给系统应用。
- 复制当前页包含原 PDF、笔迹、对象与组合，创建独立源页，支持撤销/重做和导出。复制的表单保留静态外观，不复制字段身份；签名限制仍适用。
- 侧栏右边缘可拖动，宽度本机保存；最小 212px，最大 720px，同时受窗口限制。方向键微调，双击恢复默认。
- PDF 缩略图背景使用独立的全局 150 张 LRU，避免被大页面挤出；前景仍按当前笔迹/对象显示，不缓存过期编辑。日夜版本分别占用条目，源 PDF 改变自然使用新缓存身份，画布丢失时失效重绘。
- 已移除原图角标。移动工具下双击/双点 PDF 图片打开原图，日夜模式均可；大预览窗支持双指/滚轮缩放、单指/鼠标拖动、按钮与重置。优先复用 PDF.js 解码的内嵌图片原始尺寸和像素（独立图片不叠加页面文字/矢量）；不支持或超大源图回退到最多 1600 万像素的高清区域渲染，并标注回退。缩放仅变换预览，不触发 PDF 重绘；关闭释放预览画布。原文件本身的低分辨率无法增加真实细节。
- 按住笔侧键即高亮所在页图片与链接，不受当前工具限制；点中后直接打开/跳转，普通区域打开工具环。兼容侧键与笔尖组合通过 pointermove 上报，以及落笔时才上报侧键的情况；首次点击按 PDF 几何等待目标元数据，无需等高亮元素挂载。一段落笔只触发一次，抬笔但仍按住侧键时保留高亮，松开侧键/离开/失焦清除高亮。侧键必须由设备在感应范围内上报，不能通过浏览器检测超出范围的按键；真实笔硬件仍待验证。
- 增加适合宽度按钮；连续视图按最宽页面，双页按整组宽度，允许纵向阅读。前后预渲染默认 1，可设 0、0.5、1–4；0.5 为前页末半页/后页首半页，双页以当前两页之外为邻页。低优先级、逐页执行，交互/隐藏时沿用调度暂停，切换视图/倍率取消旧请求。
- 完整底图按源页保留最近 15 页；更旧的额外底图普通模式最多 200 MiB、节能最多 120 MiB，按 LRU 淘汰。详情瓦片与缩略图维持独立预算。缩放、布局或画质档位变化使完整底图失效；编辑前景不改变 PDF 底图身份。半页预渲染复用采用完整画布坐标裁剪，避免分块采样差异，临时仍需完整尺寸画布；不宣称其 PDF 运算量严格减半。
- 文档撤销/重做跳到实际修改的页面；双页视图中目标已在当前两页时保持该组页面。插删/排序按页面身份判断。LaTeX 编辑有独立的撤销/重做按钮及 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z，连续输入合并为操作，识别插入/覆盖分别记为一步；历史只保留当前编辑会话，草稿正文仍自动保存。

搜索高亮按 PDF 文本项目几何定位，特殊字体、旋转文本和不规则阅读顺序仍需更多真实文档验证。新功能未降低 PDF 背景或导出画质。打印暂不纳入。
