# 前景裁剪滞回：测试后撤回

2026-10-13，继续第二轮前景优化。结论：撤回候选，恢复已验证的共享 RAF/同步首帧/160 CSS 像素预取边界实现。源码快照和数据保留，不作为资源收益或里程碑验收。

候选尝试在同倍率、小幅滚动时复用已挂载范围，只要它仍覆盖可视区外 32 CSS 像素；越界、缩放或尺寸变化立即同步重算，不降画质，不增加等待。几何单元 4 项通过。第一份实际 Electron 回归发现放大后仍保留整页对象，已修复为尺寸变化强制重算，另冻结 A/B；失败截图、日志、完整源快照与运行资源哈希保留在 `diagnostics` 和 `evidence`。

修正版本实际 Electron 回归通过三种视图、日夜及平移位置的 10 次截图对照：9 次逐像素一致，夜间单页只有 56 个通道相差 1，超过 1 的通道为零，沿用原 GPU 截图容差。快速跳转前三帧的 48 次可见性检查没有缺失对象或笔迹；选中对象保留、工程及全页前景 PDF 导出检查通过。该画质用例是前景文档，不是扫描 PDF 或真实手写延迟证明。

工作集相加不是唯一物理内存。CPU 仅是部分资源代理，200 ms 窗口按实际样本间隔均摊，不能恢复更短尖峰；没有可信整机功率，不能转换为焦耳或续航收益。
