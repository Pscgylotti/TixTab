# SenseVoice 推理线程空转控制

本组是第三轮本地 AI 优化的一项受控实验，尚不代表第三轮或 0.3.0 完整验收。实际固定版本 SenseVoice Small INT8、CPU、两线程、语言和解码参数不变；只比较 ONNX Runtime 的算子等待策略：A 显式开启默认 spinning，B 关闭 intra/inter-op spinning，等待工作时让线程休眠。两个冻结后端只有 `backend/asr-ort.config` 内容不同。

生产实现通过 sherpa-onnx 1.13.8 支持的 `cpu:配置路径` 加载策略文件，安装包后端白名单已加入此文件。实际运行库已验证带中文和空格的 Windows 路径。缺文件时由 Python 返回运行时错误，避免底层配置加载器直接退出；最终发行包仍需核验实际资源。

依据：[ONNX Runtime 线程文档](https://onnxruntime.ai/docs/performance/tune-performance/threading.html)、[sherpa-onnx 固定版本 session 实现](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/sherpa-onnx/csrc/session.cc)。关闭空转不减少推理线程、不改变模型精度，也没有降低录音或识别质量设置。

## 固定流程与结果

自编中英文图书馆短句，PCM 16 kHz 单声道，约 4.7–5 秒；每个新进程导入运行时、加载模型、完整识别三次，两次间隔各 1 秒，常驻空闲 5 秒、显式释放、释放后空闲 5 秒。中英文分别交错运行 A1/B1/A2/B2/A3/B3，共 12 轮。没有真实麦克风录音或网络推理。

独立采样进程读取 Python 及其原生线程的累计 CPU、工作集和逻辑 I/O，避免原生调用占用 GIL 时的采样盲区。下表为每组 3 轮的中位数；范围和所有阶段见 `evidence/asr-spin-comparison.json`。

| 指标 | 英文 A → B | 中文 A → B |
| --- | ---: | ---: |
| 整段被测进程 CPU 秒 | 3.484 → 1.891 | 3.391 → 1.813 |
| 全部间歇/空闲阶段 CPU 秒 | 1.141 → 0.000 | 1.109 → 0.000 |
| 加载后首次识别 ms | 119.5 → 123.2 | 121.6 → 119.8 |
| 第二次识别 ms | 120.6 → 124.0 | 120.3 → 123.4 |
| 第三次识别 ms | 121.9 → 125.0 | 122.9 → 122.8 |
| 200 ms 窗口最高需求（核数等效） | 1.940 → 1.235 | 1.941 → 1.094 |

这一间歇工作流的 CPU 中位数减少约 45.7% / 46.5%，识别响应变化为几毫秒。CPU 计数器为零仅表示该采样精度内没有观测到增量；不是零功率。采样器自身 CPU 单独记录，没有加入上表，也没有把该百分比推广为电池续航或全部 AI 功能的收益。

## 质量与实现检查

所有轮次识别文本一致。另对两种语言分别测试原句、首尾静音、固定种子 12 dB 合成噪声、三句拼接，共 8 个素材变体、16 次实际转写，A/B 文本逐字一致。该检查证明本组配置没有改变这些样本的结果，不证明任意口音或真实麦克风准确率。实际后端 8 项单元检查通过，包含配置文件缺失保护；未改动 Whisper 路径。

PDF 与实际识别重叠运行的结果另见[联合流程报告](../2026-10-13-ai-workflow/README.md)。联合流程使用后来增加时钟元数据的采样脚本，不与本组原始脚本哈希混算。

## 复核与限制

`MANIFEST.json` 记录 57 份原始报告、日志、精确源码和证据的 SHA256；压缩文件同时记录解压后的哈希。冻结 A/B 全部后端源码、采样脚本、比较器和质量检查脚本均随档案保留。

```powershell
node scripts/verify-asr-archive.mjs docs/performance/2026-10-13-asr-thread-policy
```

复核包含配置唯一差异、12 轮来源和固定工作量、CPU/空闲/阶段统计重算、8 组文本一致性和包资源白名单。该档案的基准脚本为当时精确版本，后续脚本变化不能用于冒充当时来源。

仅这台 Surface 的三组描述性对照，没有严格固定温度和所有后台负载；未测整机功率、GPU/NPU 活跃量、操作系统和驱动资源。常驻模型仍占内存，默认闲置卸载仍为 1800 秒。不能由此宣布其它 AI 后端、真实录音链路或全部性能专项完成。
