# PDF 公共续绘准入：十二轮复测后撤回

候选只在多个活动 PDF raster 同时存在时 FIFO 轮转公共 onContinue；回调仍由 SDK 安排下一次原生 RAF，不直接执行私有绘图片段。单个 raster/eco 不增加准入 RAF，暂停/隐藏取消时钟，取消/超时清除等待者，最后一个任务恢复直通；没有闲置 RAF 循环。已安排的 SDK slice 仍可执行，不能声称抢占正在进行的绘制或硬性限制内部约 15 ms 操作预算。

机制确实减少同批续绘，但首组六轮的完整流程改善未在反向组六轮复现，双页长尾反而变高，按预先标准撤回。当前 213 份生产来源恢复画布复用保留版，候选三新模块/测试已移出生产 source，完整源码保留在冻结候选及归档。没有节能、整体削峰、第二轮或发布完成声明。

## 功能、画质和独立追踪

- 38 单元（8 准入器、7 SDK 语义集成、23 原调度/完成/缓存）与类型通过；冻结候选源码又独立运行相同 38 项通过。覆盖完成/公平轮转、取消、输入前后暂停、隐藏恢复、双超时、单任务/eco、无闲置时钟。恢复生产后原 23 项及类型再次通过。
- 原生 Electron 扫描/矢量两负载各五场景，共十次释放/取消/丢失捕获/丢失抬笔/隐藏恢复，最终 pending=0、可见背景就绪。三负载×三视图×日/夜/原色共 27 组合/369 对实际 Canvas 严格 RGBA 零差异；A 的 307 dist/electron 文件与上游保留 B 完全一致，复用其背景基线。
- 原生前景十位置（容差沿用原测试最多 1/255）、16 次快速跳转的前三帧共 48 次无漏绘、选中对象保留、鼠标/笔在三视图/倍率/栏间/行首容错/跨行选文通过；选文绑定 308 个实际文件。微弱合成差的非累积许可及原严格失败另见页面隔离质量归档，不能放宽源内容/几何要求。
- 一份独立 16 阶段 trace 绑定候选实际运行文件，未混入普通资源组。旧基线双页/连续/倍率有 PDF 的 RAF 根分别 2/15/3，最多两回调，多回调根 2/8/1；候选为 2/15/5，最多一个，多回调根均零。三份分析都要求冻结 bundle 一基行列/原文匹配；这些是 RunTask 中的原生 RAF 批次，不是硬件呈现帧、CPU 秒或焦耳。墙钟/嵌套类别不能相加，追踪开销也不能用作普通资源结论。
