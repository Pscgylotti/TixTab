**拒绝此次候选，生产恢复 A 的 ink.ts。** 目标冷任务改善，整段 CPU 接近持平，但双页缩放 P99 在本组六轮明显变高，不能缩小验收范围仅以导入改善接受。没有证明其它阶段差异都由算术改动导致；样本少、后台/温度未严格控制，全部正式轮次保留，不事后剔除。保留额外的 seeded/舍入/-0 几何回归、基准工具与冻结实验来源，继续寻找更大的对象更新及背景调度热点。

## 独立诊断

正式资源采集结束后，对相同冻结 A/B 和五文件 harness 各跑一次 trace，分别分析导入/双页缩放，均不混入六轮资源统计。导入最大主线程根任务 198.098→152.818 ms；A 的几何边界函数约 38.514 ms 样本墙钟占用消失，确认局部重复转换减少。V8 样本包含等待，不称 CPU；根任务及嵌套事件禁止叠加。

双页缩放诊断最大主线程根任务 33.799→30.781 ms，并未重现一个更长的主线程根任务。六轮该阶段实际 PDF 渲染数量都为 2、像素 4528700、缓存淘汰字节 10149620，未发现多做一批 PDF 栅格化。不能据此推断没有 GPU/合成器差异，也不能排除调度/后台噪声或宣布因果已解决；现有证据不足以接受候选。约 150 ms 的剩余首次几何/绘制成本及对象操作仍需分摊/减少。
