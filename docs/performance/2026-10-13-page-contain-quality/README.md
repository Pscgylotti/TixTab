# 页面布局隔离：显示偏差与重复操作质量观察

本项仅完成前景合成和生命周期质量观察，尚未完成背景画质矩阵、功能门槛与完整流程资源 A/B。固定尺寸页面的 `contain: layout style` 仍为实验候选，不计节能、第二轮完成或发布验收。两构建各 213 来源，仅 `src/chrome.css` 不同；基线的 307 个 dist/electron 运行文件与父归档画布复用 B 完全一致。package.json 另计，共每版 308 个运行文件。

用户允许不累积的微弱显示偏差作为优化代价。此许可不覆盖源数据、源栅格、分辨率、对象位置/层序损失，也不覆盖明显视觉回归。仍保存原始严格失败；新的观察/校准判定单独记录，不修改原报告。

## 前景原生截图与源栅格

两页混合夹具含图片、公式 SVG、文本 SVG、草图、层级组合及穿过对象的半透明笔迹。三视图、日夜、移动/缩放预览与提交共每组 24 对截图。最初直接读取源 Canvas，后改为先复制 Canvas 再读取副本，避免读回改变显示端后端。保存三个工具版本和五份完整结果，包括两组 A/A。

源图/SVG、笔迹 RGBA、几何、层序保持完全一致。复制读回版 A/B 仅三处截图有差异，最大 1/255；严格零差异判定仍失败。按已观测基线逐像素完整 RGBA 校准仍有三个新像素，最大通道差 1，原失败保留，不能把旧直接读回版校准通过冒充新版通过。

## 40 轮重复切换

每版独立原生 Electron，1440×960、DPR 2.5、固定 high/quality。先完成一次移动及缩放，然后 40 轮连续/双页/单页、放大/缩小、日/夜切换，恢复到第一页同一 Fit 几何。每轮等待已跟踪工作 pending=0、80 ms 安静、图片/字体及两次 RAF；这是质量检查，非普通资源测量的 800 ms 完成门槛，更不是 GPU fence。

共 82 个完成截图。每轮都与该版第零轮比较，而非相邻帧：

- 基线 40 轮均零差异。
- 候选仅第 27、34 轮有 2781 个通道变化，最大 2/255；其余轮零差异，第 40 轮恢复零差异。
- 两版所有轮次的源笔迹像素、源对象/SVG、位置、层序与页面几何完全相同；实际前后下载的工程内容相同，两构建工程也相同。
- 早期未修改基线在第 10 轮同样出现最大 2/255、2781 通道变化。其完整 RGBA 帧与候选第 27、34 轮逐像素完全相同。完整候选 41 帧均匹配 52 个实测基线帧中的一种，共只有两种基线帧。此校准要求完整帧字节一致，不用数值容差、不逐通道/逐像素拼接。

因此本次有限实验未发现随操作次数增长的偏差；显示结果不会写回源数据，后续显示也没有以上一帧的截图作为输入。不能推广成所有文档/驱动必定最多 1/255：严格 1/255 门槛确实失败，且原基线也出现 2/255。后者在本试验中属于已观测基线合成状态，不是候选引入的新颜色。原严格报告 `pass=false`、源内容 `contentPass=true`、独立完整基线帧校准 `pass=true` 分别保留。

## 失败与复核

最初循环工具的混合分隔符下载目标在 Windows 上中断，修正为宿主生成的绝对本机路径。下一版截图含保存提示，提示消失后产生最大 48 的界面差异；改为等待 toast 消失。再下一版在基线出现 2/255 时提前停止，保留该结果；最终工具收集完整轮次后再判断严格门槛。没有修改正式资源测量的五份固定脚本。

归档保留全部质量/失败截图、日志、工具历史、源与运行文件哈希、CSS 两侧原文和变化的实际构建文件。父归档 MANIFEST/SOURCE-MANIFEST 保持不变。构建工具在构建后仅格式化，保留的是格式化后的等价工具，不冒称构建时工具逐字绑定。

复核：`node scripts/archive-page-contain-quality.mjs --mode verify`。校验所有压缩/原文哈希、两版实际 616 个运行文件、源绑定，并独立解码重算 82 帧与完整基线帧校准。后续仍须完成严格背景矩阵、裁剪/选择/快速跳转、工程/PDF 与六轮完整资源对照，才决定是否保留 CSS 候选。
