# 前景裁剪生命周期：保留正确性修复

2026-10-13。上一次共享几何读取实验已撤回，本次只改变 `useForegroundViewport.ts` 的连接生命周期，未重新引入共享边界或移除重复测量。裁剪数学、预留/分桶、同步滚动提交、渲染倍率、颜色、对象内容及 PDF 队列保持原实现。

## 问题、修复与决定

原 effect 依赖稳定 ref 对象。子组件 layout effect 执行时父滚动区域 ref 可能尚未附着，此时 effect 退出；父 ref 随后就绪不会改变依赖，监听不再安装。实际 DOM 节点更换而 ref 对象不变也存在相同缺口。未测量的 clip 回退全量前景，不能将这一机制一概描述成页面漏绘。

现在 layout/passive 阶段协调实际页面和滚动区域节点身份。已有连接不重新建 observer；晚附着时补建，节点替换时先清理旧连接。初始 layout 测量保留完整可见回退，正常滚动仍在共享 RAF 中同步提交，卸载立即取消旧监听/observer/待执行帧。不新增计时器或轮询。

保留为正确性修复，不计作节能优化或第二轮已完成。隔离回归在原实现收到已测量页面数 0（期望 8），修复后通过。更重要的是，真实冻结 Electron 点击连续→单页、双页→单页两条路径时，原版前景事件账本增量均为 0；修复版均为 1。原版普通导入已有容器、刷新恢复和完整进程重启均可正常绑定，不能把模式切回问题推广为所有启动都失败。
