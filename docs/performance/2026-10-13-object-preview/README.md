# 对象移动/缩放预览：实测后撤回

结论：这次减少对象复制与 React 更新的候选未证明目标收益，已只恢复 `ObjectLayer.tsx`；当前 211 份生产源码/配置与测得 A 快照逐项哈希一致。其它已验证的增量笔迹、前景裁剪、异步组合编码等保留。新增对象预览、取消/切页/撤销回归和诊断工具保留，未发布版本。

## 机制与完整流程

A 沿用原有 React 对象预览；B 每帧直接设置选中 DOM 对象的原始 left/top/width/height，避免复制整页对象和协调其 React 元素。未改用 transform 缩放、低清位图或降采样，也未改变最终对象变换、图像、滤镜、层叠或导出。A/B 的 211 份来源仅 `src/ObjectLayer.tsx` 不同。

固定磁盘素材：16 页矢量 PDF，第一页 3000 笔、240 个混合/嵌套对象。相同高画质、1440×960 内容窗口和五文件测量 harness，使用应用任务完成门槛，计入导入、实际选择/移动/角缩放/组合/层序/撤销重做、工程保存/PDF 导出、笔迹、擦除、连续滚动、双页缩放、日夜切换、公式与空闲/隐藏恢复，共 15 阶段。顺序 A1→B1→B2→A2→A3→B3；六轮均保留，无事后剔除，计数器不匹配区间均为零。未在测量期间运行构建、测试、压缩或 trace 分析。

## 质量与修正的验证方法

固定两页、小数坐标、非相邻多选、透明 PNG、草图 SVG、公式、文本、组合及穿过对象的铅笔，覆盖日夜两种主题、三种视图和移动/缩放。

初始浏览器“预览=提交截图”检查失败，少数透明边缘颜色通道相差 1；旧实现也存在，原生旧实现对旧实现重复对照同样出现 2 个通道差异。全部原始截图和失败报告保留。还有测试把右下角缩放错误地断言为左上角 x 必须变化，已修正为检查宽度。没有通过降低生产画质或设置截图误差容限来让测试通过。

最终原生验证在每种阶段额外记录源图、滤镜、透明度、尺寸和实际图像 Canvas 栅格，以相同方式执行 A/B；24 组同阶段页面截图解码 RGBA 全部零差异，120 组图像栅格/源/滤镜及对象几何/层序完全一致。它证明固定验证步骤下的等价性，不宣称普通运行的所有截图、预览和提交永远逐像素相同；额外的 Canvas 读回可能影响绘制状态，故初始失败对照保留，并且质量步骤不进入资源跑分。

浏览器回归核对预览不提前提交工程、非选中对象/层序不变，以及 pointercancel、工具切换、同 ID 跨页替换、撤销后晚到的 pointerup 不提交过期坐标。候选时新用例和已有选择/裁剪检查共 8 项通过（失败修正后的目标用例另跑）；恢复生产后再完整运行同一组并保存结果。

六轮实际工程完整重建均为 16 页、240 个唯一嵌套子对象、3000 笔，精确变换、层序和元数据一致；六 PDF 完整间接对象图含批注外观、原始流、图像/遮罩、资源，忽略日期后相同。输出与素材、冻结 model 来源均保留，核验工具会从归档解压并重建全部结果。

## 独立追踪与下一步

另外各跑一轮 A/B 的同一 15 阶段 trace；其 CPU/帧数据不混入上表。对象阶段最长主线程根任务 A 54.605 ms、B 74.455 ms，分别包含 Paint 50.525/55.709 ms。嵌套事件时长重叠，不相加，也不把 trace 的墙钟时间当能耗。该证据支持优先检查绘制失效范围与合成路径，尚不能单独归因所有帧差异。

下一步：保持原始图像、压感轮廓、透明度、层序和导出不变，检查对象/笔迹前景重绘范围、强制布局、可见区域更新及输入期间 PDF 队列；同时检查重复创建并取消的恢复计时器。每项仍需质量、完成门槛、完整流程 A/B 后决定，不能仅凭少分配或少回调判定省电。
