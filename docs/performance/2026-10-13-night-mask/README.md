# 夜间逐页阅读与精确遮罩复用实验

2026-10-13。**候选撤回；新增的逐页阅读测量保留。** 两份冻结构建仅工作线程的遮罩缓存预算不同（A 为零，B 为 24 MiB / 八项）。不改变画质、颜色策略、压感、PDF 栅格缓存、并发调度或 60 秒 worker 释放时间。缓存以完整尺寸及有序多边形坐标比较，复用原始 RGBA 遮罩，不简化边缘；键的内存另有几何数量及项数上限。

固定扫描素材 16 页，三组交错 A1/B1/B2/A2/A3/B3。使用磁盘文件导入；新 `--night-reading` 阶段在连续视图用实际“下一页”按钮逐页阅读，核对页码及夜间背景标识，每页等待任务台账/可见 PDF、对象、瓦片就绪、800 ms 稳定及两帧复核，再恢复日间和首页。每轮共 12 阶段，逐页阶段 18 个完成检查点，全部无失败/未完成任务或累计 CPU 计数缺口。它覆盖逐页停稳阅读，不能代替真实触控惯性滚动或不等页高的全部场景。

每轮候选命中 30 次，约 93.75% 遮罩像素免于重新绘制/读取；处理阶段墙钟约 -8.1%，目标阶段 CPU 约 -1.1%，完整流程约 +3.3%、最大需求约 +4.7%。连续滚动 P99 25.0→33.2 ms、双页缩放 P95 50.0→66.5 ms、公式 P99 58.4→74.9 ms；完整表及原始范围见 `comparison.json` 和 `comparison.md`，扩展内存/命中/完成数据见 `evidence/night-mask-summary.json.gz`。

这些是少量重复的描述性结果，后台、温度和 GPU 状态未严格隔离；特别是缓存尚未启用的早期阶段也有波动，不能断言所有变差都由此机制引起，也不能以局部命中率证明整段收益。工作集是进程之和，含共享页重复统计，不是缓存独占字节；其下降同样不能推导出减少了缓存内存。没有足够的整体资源/流畅度收益支持新增常驻缓存，因此生产恢复实验前的实现。试跑单列，不混入三组统计。

画质独立检查：实际 Electron 工作线程 24 项，涵盖不同尺寸、不同像素内容、透明输入、旋转/分数坐标/重叠/裁剪边缘，12 次命中，全部 RGBA 零差异；oracle 是缓存前完整 worker，不是新 helper 的另一份复制。该专项从冻结源码转译执行；另用实际应用运行产物对扫描、密集矢量、复杂前景 × 单页/连续/双页 × 日间/夜间/原色共 27 组合的 PDF、缩略图及高清瓦片逐一比较。原始像素及报告归档，重算解码后 RGBA 哈希；原色指整个页面，不包含点击位图查看原图弹窗。核验结果以归档工具输出的实际对数为准。

14 项单元检查包括缓存键/变更隔离、LRU/字节和项数上限、零预算/超限/纯矢量路径、台账以及全部 16777216 种完全遮罩 RGB 的旧算法对照；类型检查通过。画质检查和构建、压缩未与资源测量并行。

`MANIFEST.json` 记录六份正式报告、工具、全量源码、差异运行产物、素材及去重像素。模型/ORT/WASM 未改变，不重复分发，实际冻结文件由运行清单逐项验证。可在原工作区执行 `node .cache/archive-night-mask.mjs --verify`，或使用归档内的同名脚本恢复到 `.cache` 后执行；脚本会调用 `scripts/verify-render-archive.mjs` 并重新解码像素。资源重跑使用相同冻结 app、扫描素材和 `scripts/benchmark-workflow.mjs --night-reading`；恢复完整源码快照后才可重建实验候选，不将已撤回代码误称为当前生产实现。

CPU 是未校准的需求代理，GPU 进程 CPU 不等于 GPU 设备活跃时间；能量、内存传输、IO、GPU/NPU 数据不可得时保持 null。完成门槛不等于 GPU 栅栏或整机空闲，也没有等待 60 秒 worker 资源释放截止。本项不是第三轮本地 AI、真实能耗或 0.3.0 发布验收。后续优先检查更完整的背景栅格化/拷贝开销、对象编辑/组合/导出以及推理与交互协调。
