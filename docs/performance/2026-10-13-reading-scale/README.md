# 阅读底图按实际倍率复用：完整对照后撤回

2026-10-13。候选只修改 `ReadingView.tsx`：将背景位图 effect 的依赖从停稳 CSS 宽度改为同一策略计算出的实际量化倍率。仍保留 200/320 ms 宽度停稳、可见性、PDF/页面身份、日夜、密度策略和最终像素。目的是避免倍率不变时重复复制底图，以及缓存淘汰后可能的重复绘制。

## 决定

撤回候选，当前 211 份生产来源与 A 一致。实际重复工作已复现，但完整流程没有证明累计需求与尖峰改善；局部任务更少不代表整体省电。保留停稳缩放测量、像素/日夜/重挂载回归及完整证据，不计作第二轮完成或版本发布。

## 实测与追踪

- 固定 16 页、首面 3000 笔/240 混合及嵌套对象；A1→B1→B2→A2→A3→B3，各 16 阶段，所有进程计数区间匹配，已跟踪任务完成且返回稳定空闲。没有并行构建、测试、压缩或追踪。
- 新增 `--reading-scale-cycles`：在原 15 阶段完整流程中增加五次停稳缩放，目标倍率 1.05、1.10、1.02、0.82、1.08；每次实际派发 UI 滚轮事件并等待补绘/保存完成，记录五个检查点。同时覆盖同一分辨率区间和跨区间，不能只测快速往返而让 debounce 不发生。原工具默认流程保持不变，新旧工具报告不混合比较。
- 浏览器初版复现：画布尺寸及 PNG 不变，旧实现仍增加两次显示任务（9→11）。候选通过六项检查，包括同区间复用、跨区间更新、日夜/原色、连续页面离开虚拟区后恢复，以及现有完成门槛与笔迹编辑/重挂载。
- 撤回后保留像素/身份/倍率/日夜回归，并记录当前同区间仍有两次重复显示任务；没有把移除实验性能断言当作优化通过。初版与候选的性能断言源文件、原始失败日志/截图均保留。恢复后六项浏览器和类型检查通过。
- 三种输入 × 三视图 × 日间/夜间/原色，27 组合、369 对实际 PDF 底图/缩略图/瓦片/原图画布解码 RGBA 零差异。质量读回只在独立会话进行。
- 六份工程元数据/层级/几何及六份 16 页 PDF 完整间接对象图一致，仅忽略日期。首次检查器仍要求旧的 15 阶段而拒绝新报告；另存 16 阶段检查器并要求五个缩放完成检查点，保留失败日志，未放宽 PDF/工程内容检查或修改旧归档工具。

单独采集了初始基线、同一新工具的 A/B 共三份 trace。初始追踪不能与新工具统计混合；归档保留旧测量脚本并核对它的五文件哈希。新 A/B 的快速双页缩放最长主线程根任务约 29.435→49.505 ms，根内可见共享前景 `flushSync` 更新、两个 PDF.js RAF 续绘与底图 `drawImage`。代表性采样调用栈已定位到实际冻结 bundle：前景测量读取页面/视口边框，底图显示设置画布尺寸并复制位图。停稳阶段根任务约 19.336→17.802 ms，但 `drawImage` 的聚合采样时间没有明确下降。

这说明重复复制不是唯一热点；下一步检查前景几何读取、PDF 续绘与完成复制集中同帧的问题。追踪/采样本身有开销，原生函数叶节点可能合并多个调用者；代表性栈不代表全部采样的唯一来源。嵌套时间不相加，根任务是墙钟而非 CPU 或能量，也不能以两份独立 trace 解释全部普通跑分差异。

## 限制与复核

CPU 是未校准需求代理；GPU 进程 CPU 不是 GPU 硬件活跃，GPU/NPU/内存传输/I/O/实际唤醒和整机焦耳仍未知。工作集之和不是唯一物理内存。诊断开启、合成指针、少量重复及未严格控制的后台/温度限制结论，未做真实笔延迟或省电百分比声明。
