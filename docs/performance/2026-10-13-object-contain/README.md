# 对象 CSS 绘制隔离：质量门槛拒绝

候选已撤回；仅恢复 `src/chrome.css`，当前全部 211 份生产源码/配置与实验前 A 的哈希一致。新增原生质量验证可保留选中框/缩放手柄，增加属性拆分诊断与归档复核工具。没有开始资源 A/B、没有把候选计入节能优化或发布版本。

## 来源与设计

上一轮对象预览 trace 的最长主线程任务含约 50–56 ms Paint；减少对象复制/React 协调未证明完整流程收益。因此探索把 `.placed-object` 标记为 `contain: layout paint style`，附加 `overflow-clip-margin: 2px`。目的是限制失效/绘制范围，保持原始图片、CSS 几何、z-index、滤镜和提交方式；没有使用低清缓存、transform 缩放或修改 PDF/笔迹数据。

[W3C CSS Containment 规范](https://www.w3.org/TR/css-contain-2/#paint-containment)说明 paint containment 会限制溢出、创建定位/层叠和独立格式化上下文。规范所描述的可优化范围不保证应用实测收益，也不保证已有页面的光栅显示不变，必须先做质量检查。

A/B 各冻结 211 份源码/配置，仅 `src/chrome.css` 不同；运行时分别保留文件清单/哈希和有差异的实际编译资源。主程序及其它前景、背景机制不变。

## 真实 Electron 质量结果

固定两页，小数坐标、非相邻多选、透明 PNG、草图 SVG、公式、文本、组合与穿过对象的铅笔；保留选中边框和角缩放手柄。日夜 × 三种视图 × 移动/缩放 × 预览/提交，共 24 组同阶段页面截图对照。

- 24 组页面解码 RGBA 全部有差异；每组不同通道数 3120–24446，最大单通道差异最高 221。
- 120 组实际图像 Canvas 栅格/源图/滤镜及对象几何、层序记录相同；运行无 pageerror。源素材相同不能代替最终页面显示检查。
- 差分定位涉及对象内容的轮廓和字形边缘，不只是选中框。`diagnostics/object-contain-difference.png.gz` 是日间单页缩放结果中通道差异大于 1 的红色标记图，白色部分表示未标记。
- 不把“数据仍相同”当作页面严格等价。此结果说明当前接入没有通过保持显示的验证，不能据此推断所有设备上的 CSS containment 都会降低画质；本实验没有对主观清晰度或能量做量化结论。

## 最终复核

首轮归档复核发现 Chromium 会将 `layout style paint` 的计算值序列化为规范等价的 `content`，验证器最初按词表比较而报错；补充等价关键字归一化后通过。原始失败日志保留，没有放宽像素、几何或层序要求。已实际重验 422 份源码、616 项运行文件、24 组不等的页面像素、120 组相同图像栅格记录及 28 份属性截图，并逐项核对当前 211 份生产来源恢复到 A。追加核验日志/修正工具后共 792 份证据；最终再次完整复核。本轮没有资源跑分、能耗结论或版本发布。
