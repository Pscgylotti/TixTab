# 未采用的线程采样器探索

此轮 NPU 冷构建使用同进程 Python 线程采样，原生编译持有 GIL 时采样停顿，最大样本间隔 **42264.056 ms**。因此不能用它描述 200 ms 尖峰；没有纳入后续 17 份资源基线。

原报告中的阶段累计 CPU 读取仍保留，但不把这一轮与新采样器的结果混合统计。目录保存原始 gzip JSON、当时的采样代码、依赖源码、日志与哈希清单，保留失败原因而非只保留通过结果。

后续改为独立进程读取 Windows 计数器，真实阻塞/CPU/读写验证通过；NPU 冷构建时最大间隔约 234 ms。详见 [新基线和限制](../2026-10-13-asr-baseline/README.md)。
