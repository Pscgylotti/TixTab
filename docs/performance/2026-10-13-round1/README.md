# 0.3.0 第一轮：合并公式草稿写入

**后续审计修正：** `round1-1.json.gz` 的 setup 阶段出现首次 CPU 累计读数倒退，约 213 ms 区间不完整。下面整段 CPU 中位数和 -4.7% 仅保留为历史观察，不再用于整轮验收。首次计数器初始化及异常拒绝加入基准后，已另做[完整三组复测](recheck/README.md)：六轮全部通过，公式阶段 CPU 中位数 -12.6%、整段 -3.2%，保存仍为 253→2 次，以新组支持第一轮验收。原始记录没有改写，见[审计记录](../2026-10-13-ai-workflow/README.md)。

第一轮机制是公式画板草稿的有界合并保存。原实现每次落笔和每次源码光标变化都克隆完整草稿并写 IndexedDB。新实现停顿 250 ms 后读取最新状态并保存，连续编辑时最长 1000 ms 保存一次；关闭、插入后卸载和 pagehide 立即冲刷尚未提交的修改。已开始的数据库写入不取消，最终事务仍计入完成门槛。异常退出可能丢失最近至多一秒的尚未提交编辑，正常退出和已确认保存的内容不依赖延迟定时器。

基线与候选分别运行三次，A1/B1/A2/B2/A3/B3 顺序交替。三次基线都写入 253 次，候选都为 2 次。公式阶段 CPU 时间中位数 3.479 → 2.939 秒（-15.5%），P99 帧间隔 83.3 → 66.6 ms；整段采样累计 CPU 15.651 → 14.915 秒（-4.7%）。整段 CPU 范围分别为 15.549–18.478 和 14.751–15.596 秒；这些是少量合成场景的描述性测量，不代表统计显著性或电量收益。其它阶段有波动，不能归因为此改动；连续滚动、双页缩放的尖峰仍需后续处理。

每阶段等待实际已跟踪任务结束、800 ms 计数安静窗口、可见 PDF/细节图块就绪及两帧再次检查。包含窗口隐藏后恢复的补绘和公式数据库保存。未启用诊断时不额外轮询，计数器不包含文档、音频或凭据。测试工具的 100 ms 完成轮询与 200 ms 进程采样开销计入流程；尚未单独剥离测量开销。完成门槛不是 GPU 完成栅栏，也不是整机空闲或能耗测量。60 秒夜间工作线程闲置回收未纳入此短流程。

固定样本：40 页、3000 条笔迹、80 个对象，seed 813；画质 high、日夜往返、相同窗口和硬件。原始报告包含完整构建资源哈希、脚本哈希、逐阶段任务账本、进程 CPU/内存、长任务和帧采样；MANIFEST.json 记录压缩文件与解压后报告的 SHA256。两组构建已在本地独立目录冻结。运行时哈希识别实际受测资源；工作区 diff 哈希也包含未打入冻结构建的后续界面编辑，不能独立作为源代码重建依据。

正确性证据：有界延迟/连续编辑截止/同步冲刷隔离的 3 个单元测试；草稿向量、源码、光标、多行、清空、文档与对象隔离、关闭恢复和 pagehide 重载测试；公式识别覆盖/插入及取消回归；实际 IndexedDB/绘制任务完成测试共 9 项浏览器检查通过。画板绘制算法与画质未改变。

硬件：Core Ultra 5 238V、Arc 130V、2880×1920/120 Hz、连接电源、平衡计划。未获得可靠整机功率；GPU 进程 CPU 不等于 GPU 硬件用量；本组不包含 AI 推理、实际麦克风或真实手写笔延迟测量。
