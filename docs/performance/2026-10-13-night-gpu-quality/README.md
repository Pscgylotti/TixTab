# GPU 夜间转换：质量诊断（2026-10-13）

**尚未通过质量验收，没有性能/能耗结论。** 工作区在并发实验期间新增 GPU 夜间颜色转换；该改动未被先前十二轮冻结测量覆盖，故单独检查。

真实 Electron 中运行 CPU 参考和新 GPU worker，包含不透明/透明输入、不同尺寸、三组像素、四种图片遮罩（无、全覆盖、分数旋转/裁剪、重叠），共 48 对。测试只给 worker 返回值增加实际执行后端标识，不改颜色计算。48 项全部实际走 WebGL2，没有用 CPU 回退冒充 GPU 验证。

原版不透明样本最高差 1/255，透明样本最高差 37/255，48 项均有严格 RGBA 差异。因此源码中“最多一个 8 位等级”的一般说明尚不成立；透明通道的反预乘/量化需另行处理。原始 PNG 与失败报告保留。

另在临时来源中尝试输入/输出整数化并关闭 GPU dithering：24 个不透明样本严格一致，24 个透明样本仍有差异，最高 26/255。该临时版本没有覆盖生产源码，也不作为完整修复。测试像素为固定生成模式，不能把这 24 个不透明样本推广为所有 RGB 颜色/真实 PDF 已完全一致。

`node scripts/archive-night-gpu-quality.mjs --mode verify` 独立解码全部 192 个 PNG，重算 96 对不同通道数、最大差与超过一级的通道数，核对源码、参考实现、实际 GPU 标识、仪器化代码、报告和证据哈希。只验证诊断证据，不把严格失败改写成通过。
