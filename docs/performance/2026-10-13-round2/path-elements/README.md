# 阅读笔迹路径节点复用

本组保留一个页面内的路径节点复用改动，作为第二轮的增量结果。三组交错完整流程中资源收益较小；不代表第二轮、整体能耗或 0.3.0 已整体验收。

## 改动与固定条件

原有 `StaticInk` 每次可见集合变化时重新创建全部可见 `<path>` 元素。候选在该已挂载层内用 `WeakMap<Stroke, ReactElement>` 复用不可变笔迹对应的原生路径元素，按原查询顺序返回；同 ID 的新笔迹对象重新生成元素。没有增加每笔 React 子组件，没有改变轮廓、点、透明度、夜间处理、层序、裁剪边界或高清目标。缓存随所属层卸载释放，不能放进全局笔迹缓存而通过元素 owner 留住旧页面。

A/B 都保留前景裁剪和首帧同步提交；冻结源目录仅 `src/PageEditor.tsx` 不同，其余源文件逐项相同。相同 3000 笔/80 对象/40 页样本、1440×960 窗口、画质、完成门槛和脚本，依次 A1→B1→A2→B2→A3→B3；全部六轮保存，没有事后丢弃首次较慢的 A1。样本、设备、版本、电源记录及实际运行资源身份在原报告中。

- B 构建 SHA256：`cd0bcaf8fbd85eff7acee32218aee0041117735f5e8fee2faa9b1a122636f9ed`。

整段 CPU 中位数下降约 1.4%，连续滚动约 2.0%，双页缩放约 3.4%；帧间隔接近，P95 的 0.1 ms 变化不解释为实质改善或退化。整段 CPU 范围 A 13.276–14.598、B 13.298–13.420 秒，范围重叠；隐藏/恢复 CPU 中位数增加约 9.8%，没有声称所有阶段更快。具体操作和范围见 [comparison.md](comparison.md)、[comparison.json](comparison.json)。不将本组百分比与此前不同构建的裁剪收益直接相加。

工作集和私有内存的总峰值略高，渲染进程私有内存中位数接近；这些是采样到的进程求和，包含共享页、运行库和 GPU 进程，不能直接当作唯一物理内存或路径缓存大小。当前只能说未发现卸载后旧渲染节点残留，不能说整体内存下降。继续保留完整峰值和范围，后续扩充长周期/多文档矩阵。CPU 需求模型未校准为焦耳，没有 GPU/NPU 硬件活动或可靠整机功率，不声称节能或续航百分比。
