# 第二轮前景裁剪：早期探索记录

**本目录原六轮结果对应早期候选，已被后续构建替代。** 首帧漏绘修复后的独立六轮、真实 Electron/浏览器回归及 PDF 导出证据见 [final/README.md](final/README.md)。旧结果与失败记录保留，不混入新组统计。后续连续滚动更新成本的优化仍在实施；第二轮尚未整体验收。以下是旧候选当时的状态和限制。

当前机制：页内对象通过 R-tree 查询逆变换视区，外扩 160 CSS 像素并向外取 64 像素桶；保留原始层序、已选中/拖动/尾擦待删除对象。阅读态笔迹使用无需提前生成轮廓的保守包围盒筛选 path；单页已提交墨迹仍保留整页增量 Canvas。小场景跳过裁剪，滚动面板共用监听和一次动画帧测量，平时无轮询。原始工程和导出不删减内容。

**本轮仍未达到 0.3.0 验收条件。** 普通编辑、夜间、公式草稿、聊天及设置等扩大浏览器回归中 32 项通过；新增前景严格截图测试出现不稳定差异。曾有单次完整测试通过，随后三次稳定截图对照仍失败，不能用单次通过替代最终验收。首次可见差异为 50 个像素、单通道最大 1，位于图片边缘；另一轮夜间滚动差异为 1558 像素、最大 25。已保留失败截图并继续定位浏览器合成/参考场景和实际裁剪的关系，未放宽像素判断，也未认定全部差异都是测量噪声。

固定画质完整工作流的 A1/B1/A2/B2/A3/B3 六份候选报告已归档。整段 CPU 中位数 14.290 → 13.779 秒（-3.6%），双页缩放 CPU 2.449 → 1.896 秒，P99 帧间隔 241.6 → 108.4 ms。基线整段 CPU 范围 13.793–25.688 秒，候选 13.683–14.364 秒；A3 多个阶段明显变慢，原因尚未确定，保留该轮，未以异常名义删除。少量合成用例和明显离散不足以建立统计显著性或节能结论；隐藏/恢复阶段候选 CPU 中位数也更高（0.386 → 0.463 秒）。

与第一轮使用相同工作流/完成门槛，但本轮 A/B 是各自冻结的新构建，不将第一轮旧基线混入。每阶段已跟踪任务 pending=0、无失败，含恢复后补绘/保存；这不是 GPU 栅栏或整机空闲。无真实功率、GPU/NPU 硬件活动和模型并发测量，不宣称耗电比例。

`MANIFEST.json` 包含压缩/原报告及构建、测试脚本哈希；`SOURCE-MANIFEST.json` 记录本地冻结源文件哈希。两组运行时和源文件副本在 `.cache/performance-030-round2-before` 与 `...-candidate`，保持不变；报告中的工作区 diff 另含未打入冻结包的文档变化，不能单独用于重建。

323 个单元测试在最多两个 worker 的完整复跑中通过，类型检查及生产构建通过。首次默认高并发测试有一个几何用例超过 5 秒，控制并发后完整复跑通过，未删除或降低该用例。裁剪坐标、保守压力边界、缓存路径/旧压感输入与正常编辑仍有独立检查；严格截图问题解决、快速移动与原生环境复核通过前，本轮保持未完成。
