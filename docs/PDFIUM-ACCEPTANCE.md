# PDFium 迁移验收清单

请使用 0.3.4 安装包检查此次 PDFium 迁移；已安装的 0.3.3 不包含这些修改。

勾选表示你在真实文档上确认通过；以下人工项目尚未代替你勾选。建议至少使用一份英文论文、一份整页扫描图 PDF、一份混合尺寸/旋转页面的 PDF，以及你之前预览失败的文件。

## 优先检查

- [ ] **PDF 元素暂存与预览**：修改一段文字，等待预览；关闭编辑框后暂存仍可见，原文件没有被写入。移动/缩放图片和文本框也能预览。出现失败时，编辑框内能看到具体原因及“重试”，不只剩空白。
- [ ] **应用/撤销/导出**：点击“应用 PDF 编辑”后，新文字可搜索、没有乱码、字号和基线合理；撤销能恢复。未应用的暂存修改也能随导出生效。用另一个查看器重新打开导出结果核对。
- [ ] **高倍率缩放**：文字页和整页扫描图连续放大/缩小，有旧画面过渡，停稳后变清晰，不持续黑屏。三种视图都检查。
- [ ] **原图**：移动工具双击图片，检查尺寸、清晰度、方向、透明区域和颜色；缩放、下载、复制、OCR 信息按钮可用。夜间显示与保存原色分别正确。

## 阅读、选择与导航

- [ ] 单页、连续、双页切换后，页面尺寸、裁切边界和旋转正确；混合尺寸 PDF 不错位。适合页面、适合宽度、页码跳转正常。
- [ ] 英文整段选文保留空格/换行；中文、公式附近、竖排文字和反向选择没有明显错位。复制、翻译、朗读仍可用。
- [ ] 搜索全文，点击结果及上一项/下一项均定位到正确页面与区域；目录树、书签、引用返回/前进正常。
- [ ] 网址、跨行链接、arXiv 编号、竖排 arXiv 和邮箱的高亮及跳转位置正确。
- [ ] Alt 或笔侧键高亮并允许点击交互；开始拖动框选笔迹后停止交互高亮。整页图片不会盖住笔迹或选择框。
- [ ] 撤销/恢复定位到生效页；双页右侧页已显示时，不错误翻到另一组页面。

## 位图、OCR 与截图

- [ ] 解析位图：当前/指定/全文数量合理，开始、暂停/停止、重试、跳过已有结果正常；关闭后不会继续识别。
- [ ] 打开已有 OCR 的 .tixtab 工程，文字仍附着在原图片上；搜索/选词/高亮没有错绑到其它图片。组合对象、重复图片和批注中的图片也检查。
- [ ] 提取图片窗口显示所选范围内位图数，切换当前页/全文/指定页能更新；包含插入图片和组合内位图。导出的数量、原色、透明度及文件名正确。
- [ ] 从 PDF 左/右/上/下的空白处开始截图或裁剪，或反向拖动到空白处，选择框自动限制到 PDF 边界。裁剪只作用于指定目标页，采样后百分比及预览正确；鼠标和触屏都检查。

## 编辑、保存与批量批注

- [ ] 手写、擦除、压感、选中笔迹移动/缩放、对象剪切复制粘贴、便签及其锚点位置保持正确。
- [ ] 插入/删除/复制/旋转/裁剪/重排页面后，搜索结果、书签、链接、笔迹和便签仍对应正确页面。
- [ ] 页面复制到另一个文档、保存 .tixtab、重新打开和导出 PDF 均可恢复编辑内容。
- [ ] 原有表单的文字值和勾选框可见；导出后字段值、页标签、原始批注和元数据保留。若在表单上覆盖笔迹，请额外比较另一个查看器：控件与导出 Stamp 的层叠仍存在原有跨查看器差异。
- [ ] 连续批注切换到从未打开的文件时继承上一份的视图模式；返回已打开的文件时恢复它自己的模式和阅读位置。文件仍按需读取，一个批次仍在一个 tab 中。

## 资源与稳定性

- [ ] 翻页、切换文档、关闭文档后没有旧页面残留或串页；OCR/图片导出完成或停止后，后续任务仍可启动。
- [ ] 普通/节能/极低内存设置下均检查一次长文档翻页与 OCR 停止。观察内存是否在多次完整任务后持续无界增长；不要把常驻引擎的可复用 WASM 高水位单独判作泄漏。
