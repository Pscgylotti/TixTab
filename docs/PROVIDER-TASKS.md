# 任务与后端（0.2.17–0.2.18）

入口为设置 → 任务与后端，公式与 OCR 面板底部也可打开。显示请求的后端、当前尝试或最终实际后端、模型、设备、排队/运行/回退/取消状态、尝试次数及耗时。能力列表包含各后端的输入/输出、流式支持、取消支持和本地模型包 ID。朗读任务只跟踪语音合成，播放仍使用原有暂停/继续/停止控件。

四项功能及 HEAD 连接检查共用 Provider 接口。本地推理最多一个、远程最多两个、系统声音准备最多一个；每项功能不允许重复启动同类任务。队列取消不会发送请求，执行中取消会等待适配器释放资源再放行下一个任务，迟到消息不会更新界面。统一截止时间上限为 180 秒，远程请求同时保留各自配置的较短截止时间。

启用远程失败回退后，网络不可用等失败转到选定的本地实现；取消、超时、忙碌及无效输入直接结束，避免重复推理。翻译已离线时可跳过远程请求。原生服务拒绝的请求不会另起浏览器模型。显示实际设备，包括原生不可用后转为 WASM 的结果；无需推理的翻译返回“无需推理”。

切换 WASM 模型/翻译方向时释放上一份浏览器模型；0.2.18 的本地免推理翻译直接返回，保留已有热模型，不加载模块或请求原生释放。任务记录只在内存保留最多 20 项已结束任务与全部活动任务，不保存选区文本、图片、结果、接口地址和凭据；仅打开面板时订阅更新，无空闲轮询。

0.2.18 的“释放闲置模型内存”复用本地任务队列，排在当前任务之后，不中断推理；关闭面板会取消尚未执行的释放。释放本窗口追踪的浏览器 worker，并向已经存在的原生服务发送固定 `POST /models/release`，正文仅 `{"action":"release-idle"}`，不启动服务、不加载模型。原生服务在共用锁内释放模型并取消闲置定时器，正在推理时返回 429；拒绝外来 Origin 与其它 action。

原生健康能力声明 `release-idle` 时，本窗口转入 WASM 或原生内部回退前请求释放原生闲置模型；忙碌拒绝不会启动竞争的 WASM 推理。未使用过支持该能力的服务时不额外发请求。旧服务或不可达服务保持原有兼容路径，手动释放会报告状态，因此不声称所有窗口/后端的模型内存合计只能有一份。多个窗口仍各自拥有浏览器 worker。

原生服务仍在最后一个请求结束后保留模型 120 秒；用一次事件循环定时器代替每 15 秒的循环检查。新请求取消旧期限，结束后重新设置；实际释放、手动释放和服务退出后不再保留闲置定时器。截止略早触发时只补足剩余间隔，不恢复周期轮询。

真实本机 Texo NPU/CPU 两轮释放及重新加载通过，模型 weakref 释放、health.loaded=false、闲置定时器取消，结果均为 `X`。工作集从约 401 MiB 降到 160–162 MiB，私有提交量减少约 143–149 MiB；使用已有编译缓存，数据见 [测量记录](benchmarks/model-lifetime-20261011.json)。保留了运行时与文件缓存，不能把这两轮观察推广为整机显存、任意文档或续航结论。

Tesseract.js 固定为 7.0.0，使用其 worker 消息协议管理实际 OCR 线程。核心/语言初始化与识别阶段取消都会终止线程并拒绝等待中的任务；下一次识别重新初始化。热线程复用，120 秒闲置释放，180 秒超时也释放。升级 Tesseract 时必须重跑真实离线 OCR 和初始化取消后重试回归。

目前验证包含调度并发/排队取消、执行中取消等待清理、截止/迟到消息、记录上限/隐私、实际回退元数据、界面任务取消、真实 Tesseract 取消重试和 Piper 中英语音。真实付费 API、更大质量样本和硬件功耗测量仍待继续验证。
