# 本地文档矫正与五线谱识别

入口：额外工具 → 文档矫正 / 五线谱识别 / 五线谱播放器。

## 文档矫正

- 当前页、全文、指定页；也可点击指定图片。
- 批量先统计几何索引，逐张加载、处理、释放，不提前解码全文。
- 扫描倾斜采用 OpenCV；透视与曲面采用 UVDoc ONNX。支持前后预览。
- UVDoc 复用已有 OpenVINO Python 环境。CPU / GPU / NPU 可选，自动优先 NPU；不兼容时自动回退 CPU。显式指定设备失败会说明原因。
- 模型神经网格固定为 488×288 输入、45×31 输出，图像重采样在 CPU 完成。沿用原模型 align_corners / 零填充，不把 GPU/NPU 推理时间宣称为端到端时间。
- 每张图使用独立进程，结束后退出；NPU 编译缓存只保存在磁盘。CPU 线程上限 2。
- 矫正图片作为可编辑替换层置于手写层下方，保留 PDF 原始字节与批注；旧 OCR / 谱面结果失效。可撤销、保存工程、导出。

## 五线谱

- 默认 Audiveris 5.11.0；组件携带 Java，无需 Python。组件包只解包到应用管理目录，不执行系统 MSI 安装。
- homr 0.7.0 为可选后端；要求 Python ≥3.11，因此使用兼容的按需环境。模型在本地准备后离线运行，禁止识别时额外下载标题 OCR 模型。
- 识别结果（MusicXML、音符、谱行与位置）附在对应页，保存在工程与工作空间。
- 播放器使用本地 Web Audio 合成器，默认钢琴，可选常见 General MIDI 乐器音色并记住选择；MIDI 导出写入对应 Program Change。合成音色不依赖采样 SoundFont。
- 播放器支持进度、速度、音量、谱面点击定位、竖线与自动换页，适用于单页、连续和双页。
- 可修正 MIDI 音高、时值与静音，MIDI 导出采用修正结果；“原始 MusicXML”导出保留后端原始文件。
- Audiveris 使用导出布局坐标。homr 的音符位置由真实谱行范围与符号时序估计，界面明确标记。识谱可能漏音或误音，需要人工校对。
- 声音跟随为本地单旋律音高匹配实验功能，适用于清晰单旋律；不是通用复调音频对齐模型。
- 关闭播放器、隐藏应用或切换文档时停止音频与麦克风。音频最多 64 个合成声部，调度窗口约 180ms；定位层只为谱行建立交互节点。

## 检查清单

- [ ] 扫描大图预览 / 应用，原 PDF 和笔迹位置不变。
- [ ] 指定图片选择、全文 / 范围批量、停止后保留已完成结果。
- [ ] UVDoc NPU / CPU 切换；任务结束后 Python 退出。
- [ ] Audiveris / homr 结果重启后恢复。
- [ ] 点击谱面、MIDI 修正 / 导出、三种视图自动换页。
- [ ] 麦克风授权、单旋律跟随、关闭后指示灯关闭。

实测记录：UVDoc 已在现有 OpenVINO 环境完成 NPU 端到端脚本运行；Audiveris 已对示例谱面生成真实 MusicXML。浏览器模拟桥接测试覆盖 UI 和持久化；homr 的模型推理与真实声音跟随仍需设备验证。
