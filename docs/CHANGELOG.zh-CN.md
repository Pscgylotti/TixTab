## 文档标签页与自定义笔色（0.2.23）

可将多个 PDF 或 TixTab 工程拖入窗口，也可在“打开”中多选；每份文档使用独立标签。切换前保存标注、页码、缩放和预览方式，重启恢复已打开的标签；关闭标签保留工作空间文档，可从工作空间重新打开。只保留当前文档的 PDF 渲染实例，其他标签按需从本地读取。标签切换后撤销/重做记录重置，已保存内容保留；批量导入跳过损坏文件并提示文件名。

状态栏左侧按钮可收起底部浮动工具，将 OCR、草图、公式、插页、翻页、缩放和适合页面移动到状态栏，记住收起状态；窄屏状态栏可横向滚动。笔色面板支持系统颜色选择、六位 HEX 和最多 12 个常用色，颜色偏好保存在本机。按最新要求移除 Etymonline 词源入口和桌面桥接。

顶部、笔工具和底部都收起时，顶部展开按钮并入标签栏，上方两行与底部状态栏各 30 CSS px；触屏输入设备各 36 px。相较此前三行顶部加 50 px 底部，占用高度从约 162 px 降至 90–108 px。紧凑按钮保留名称和提示，窄屏底栏横向滚动。

公式窗口新增“多行手写公式”，默认按行串行识别并合并为可编辑的 `aligned` LaTeX，最多 12 行；行间留出空白，分数与上下标保持在同一行内。也可整体识别。取消或中途失败保留原有公式；自动分行仍可能误判复杂排版，必要时改用整体识别或分批书写。

新增可选实验后端 Uni-MuMER Qwen3-VL-2B（Q4_K_M 主模型、Q8_0 视觉投影、llama.cpp Vulkan）。设置 → 本地模型管理分别下载模型约 1481 MiB 与运行时约 32 MiB；完整离线包也不预装此实验模型。需要现有可选 Python 3.10 本地运行时，使用 GPU 或 CPU，未启用 NPU。切换功能和闲置 120 秒后释放模型子进程；默认仍为低功耗 Texo，可配置失败回退。详细实测与边界见 [Uni-MuMER 测试记录](docs/UNIMUMER.md)。

## 可取消的后台 PDF 导出（0.2.22）

导出时显示阶段与标注页数，支持“取消导出”和 Escape。解析源 PDF、处理文档结构、生成笔迹与保存均在短期 Worker 中执行；每个窗口同时一个导出，完成、取消、失败或离开页面时释放。源文件分批复制后传输独立缓冲区，工程内原始字节保持完整；不复制草图场景、SVG 预览或公式编辑配置。后台不可用时提示重试。

本机 134,400 点合成笔迹样本中，主线程导出的最大帧间隔约 1,182ms，后台约 14ms，输出字节一致。这是该样本的界面响应测量，不代表所有文档或实际功耗；大型 PNG 字符串复制、快照分配和最终下载仍有主线程成本。详见 [测量记录](docs/benchmarks/pdf-export-worker-20261011.json)。

## 保留源 PDF 信息的导出（0.2.21）

导出改为复用原页面，保留源文字、普通链接、批注和表单字段/外观；插页、删页和重排同步处理表单控件、本地跳转及页标签。新笔迹与插图按原页裁剪、旋转和 UserUnit 输出为每页一个矢量 Stamp 外观；不再逐页重新嵌入源内容。工程继续保存可逐对象编辑的草图、公式和笔迹。

未修改的 PDF 直接导出原始字节。含数字签名的修改文档会要求确认导出修改副本，该副本的原签名不再有效，需要重新签名；此功能不验证签名真伪。PDF.js 会把表单控件画在其它批注上方，覆盖控件的标注在不同查看器中可能显示不同。复杂 Tagged PDF、XFA、附件/动作链、加密和增量签名保存仍待完善；删页不代表安全擦除。详见 [导出验证与边界](docs/PDF-EXPORT.md)。

## 按需磁盘缓存管理（0.2.20）

设置 → 磁盘缓存管理 → 统计缓存，可查看和确认清理四项 OpenVINO 编译缓存、原生解包权重副本及浏览器模型缓存。只读目录元数据、文件大小和响应头，不扫描权重内容，不在后台轮询。无法取得的大小单独标记；清理后首次使用可能重新解包、下载浏览器副本或编译。

文档、下载模型、内置权重、运行时、自定义缓存路径和未知文件保留。OCR 与旧笔记共用 IndexedDB，因此只删除明确的语言数据键；语音只删除两种已知声音副本。更新后的原生进程用驻留句柄保护缓存，浏览器任务用跨窗口 Web Locks 协调；请先关闭旧版程序或手动启动的旧服务，旧进程不具备这项保护。详见 [模型与缓存管理](docs/MODEL-LIBRARY.md)。

## 自适应划词浮窗（0.2.19）

设置 → 书写惯用手可选择左手/右手并记住偏好。选文浮窗按实际内容尺寸定位，优先在惯用手另一侧，有空间时避开文字、笔尖和悬浮键盘；展开后端配置或窗口变小时限高滚动。浮窗按钮、链接和下拉框至少 44 CSS px，原文朗读支持键盘操作。位置只随尺寸、滚动和键盘布局等事件更新，没有周期轮询。

当选区或键盘占满屏幕时仍可能遮住部分文字，采用最少重叠位置；实际 Surface Pen 手掌遮挡待真机验收。最新工作空间夜间白块反馈暂未复现，仍保留待定位项。

## 模型内存与闲置唤醒优化（0.2.18）

设置 → 任务与后端 → 释放闲置模型内存：等待本地任务完成再释放，不中断识别。支持新生命周期接口的 OpenVINO 服务在转入 WASM 前释放闲置模型，忙碌时不会启动另一份 WASM 推理；旧服务保留原有闲置策略。原生服务改为请求结束后设置一次 120 秒释放定时器，释放后不再每 15 秒唤醒检查。无需翻译的文本直接返回并保留其它热模型。

本机 Texo NPU 编码/CPU 解码两轮“识别—释放—重新加载”结果一致，释放后模型对象消失，进程工作集约从 401 MiB 降至 160–162 MiB。这是两轮进程内存观测，不是实际功耗/续航测量。详见 [任务与资源生命周期](docs/PROVIDER-TASKS.md) 及 [原始测量](docs/benchmarks/model-lifetime-20261011.json)。

## 工作空间夜间配色与任务面板（0.2.17）

工作空间管理使用组件内的日间/夜间配色，避免后加载的全局皮肤覆盖文档列表、分组和输入框；滚动条、下拉框及竖屏分隔线统一使用深色。回归检查同时扫描横向与纵向白色像素，覆盖大量文档/分组滚动，以及草图和公式延迟加载后的窗口。

设置 → 任务与后端可以查看任务的实际模型/设备、排队与执行状态、回退和耗时，并取消任务；公式/OCR 面板也提供入口。本地任务串行运行，远程任务最多两个。OCR 在模型初始化期间也可以终止实际线程并重新识别。任务面板只在本次会话保留最多 20 项已结束任务的元数据，不记录选区和结果。详见 [任务调度](docs/PROVIDER-TASKS.md)。

## 夜间残留浅色区域补修（0.2.16）

工作空间管理的配色变量由根主题统一提供；补齐单页网格伪元素、OCR 截图预览和公式画板边框的暗色显示。OCR 仅修改显示，传给模型的图片仍保留原始颜色。页面在加载应用脚本前恢复已保存的夜间主题，桌面窗口首帧绘制完成后显示，减少启动时的浅色闪现。新增像素截图回归检查，覆盖横竖屏和草图编辑器延迟加载后的工作区。

## 按需模型与轻量包（0.2.15）

设置 → 本地模型管理：查看 8 个模型包的版本、大小、许可和 SHA256，按需确认下载、取消、手动校验或删除下载副本。下载流式写入且校验后启用，不在后台扫描模型权重。桌面 WASM 与原生 OpenVINO 共用下载目录。

`npm run pack` 生成不带权重的轻量版；`npm run pack:offline` 保留完整离线版。轻量版只需下载要使用的模型；Piper 声音与共享 phonemizer 分别安装。详情及声音许可边界见 [模型管理](docs/MODEL-LIBRARY.md)。

## 后端配置与直接连接（0.2.14）

翻译、朗读、OCR 和公式分别记住后端及 API 配置，支持自定义请求头、超时、无选区 HEAD 连接检查和 LLM 文本流式。桌面版使用 Windows safeStorage 加密保存 Key/请求头，导出工程不包含凭据；浏览器预览的凭据仅本次会话有效。公式新增 HTTP/图像 LLM，仍默认本地 Texo。修改设置不会启动模型。使用入口、协议、CORS 限制及验证说明见 [后端配置](docs/API-PROVIDERS.md)。

桌面四项 API 及连接检查均通过主进程直接连接，无需服务端开放 CORS；浏览器预览仍遵守跨域要求。响应按需以最多 64KiB 分块传递，保留流式输出，取消、超时、刷新和关窗会释放连接。不新增本地端口或依赖，不自动跟随重定向，不发送浏览器会话 Cookie。

同时修复夜间切换等待期间，连续/双页、左侧缩略图和高清瓦片仍显示旧白色画布的问题；转换完成前使用暗色纸张底色，复用既有缓存。

## 运行

需要 Node.js 22.17 或以上。

```powershell
npm install
npm start
```

`npm start` 构建后打开 Windows 桌面应用。开发时分别运行 `npm run dev` 和 `$env:SURFACETAB_DEV='1'; npm run desktop`。浏览器预览：<http://127.0.0.1:5173>。`npm run pack` 生成 x64 轻量便携版到当前版本的 `release/<版本>/lite/`；`npm run pack:offline` 生成完整离线版。

## 实验夜间与节能（0.2.4）

0.2.12 补修工作空间底色、名称输入及分组下拉框，并消除进入夜间时按钮背景的浅色过渡。工作空间管理、删除确认及空列表支持横竖屏深色显示。

顶部月亮按钮启用实验性夜间模式：应用、纸张、文字与矢量内容调整颜色，PDF 位图按图像绘制区域保留色相并降到 62% 亮度。移动工具下点击图片角标查看原 PDF 区域；“查看原色”临时恢复页面内容原色。复杂裁剪、透明叠加和图上文字可能不准确；导出、OCR 和模型输入使用原始颜色。公式画板/草图编辑器也适配暗色，公式插入仍保存日间可读的原色。

设置 → 渲染与能耗提供自动、节能、画质三个选项。桌面版读取真实电池/电源事件，自动档在电池供电时节能；节能档使用 1 路 PDF 绘制、32MiB 缓存和每页 200 万细节像素。交互期间保留画面并暂停后台 PDF 时间片，窗口隐藏时暂停；高倍率只补视区细节，整页底图倍率上限 1×/1.5×，避免反复分配大图。夜间换色在独立 Worker 中执行并缓存，60 秒闲置释放线程。这些为减少工作量的策略，尚未测量实际功耗与续航。

## 已实现的基础功能

- 打开 PDF、单页标注、连续/双页预览、紧凑缩略图；长按拖动页面排序、右键/长按管理、删除和撤销；双页默认每次翻两页，单箭头按钮或 Shift+左右方向键移动一页，便于原文/空白批注页配对。双指仅移动和缩放，不翻页。
- 钢笔、圆珠笔、铅笔、荧光笔，颜色和粗细；逐点压感、合并采样事件；尾部橡皮滑过的笔迹/插入对象先高亮，松手一次删除，取消保留。
- 笔/鼠标书写，单指平移、双指缩放，书写期间忽略触摸；Ctrl+滚轮缩放。
- 独立 PDF / 已完成笔迹 / 当前笔划画布，缩放直接变换已有画布，停止 200ms 后高清重绘。
- 低分辨率首屏、48MiB 页面 LRU 位图缓存、单页 PDF 背景最多 600 万像素；高倍率停止交互 160ms 后补绘视区 512px 高清瓦片，每页细节层上限 600 万像素，平移重用重叠块、两路优先队列；手动快速预览固定低清背景。
- IndexedDB 多文档工作空间：新建笔记、分组、搜索、置顶、重命名、导入/导出和删除；切换恢复页码、缩放与预览模式，旧自动保存自动迁入。原 PDF 只存一次，每次自动保存只写变更页。
- `.tixtab` 工程包含原 PDF 和可编辑笔迹；导出 PDF 保留原页面矢量内容并叠加矢量笔迹。
- Excalidraw 懒加载集成；每个草图独立保存场景、用 SVG 清晰显示，高分辨率 PNG 用于 PDF 导出。
- 对象工具（S）从页面空白处拖出矩形，一次框选多个草图/公式；Shift 加选/取消，Esc 取消操作。整组移动、等比缩放和 Delete 删除均可一次撤销；单个对象仍可原位再次编辑。新对象会自动带入视野。旧工程未保存场景的草图可作为图片继续编辑，不能恢复已丢失的矢量元素。
- 设置中的“界面语言 / Interface language”可即时切换简体中文或 English，选择保存在本机；PDF 内容、文档名称与公式不变，Excalidraw、工作空间、划词及 OCR 面板同步切换。
- 顶部与工具栏分别收起、记忆状态；窄屏换行、可展开页面栏；Windows Mica 与局部半透明浮层。
- PDF 文本选择（T）、双击选词、复制、笔侧键/右键划词浮窗。
- 内置 OPUS 中英双向翻译，API 出错/断网时回退本地；在线默认 Google，也支持自定义 HTTP/LLM 接口。0.2.8 可在后端设置显式选择实验性 OPUS OpenVINO（NPU→GPU→CPU 编码，CPU 解码），显示实际设备并记住偏好。
- 手写公式画板、LaTeX 编辑/KaTeX 预览、复制、插入公式；可保存 Predefine 命令和带参数宏，工程内保留公式使用的宏；默认 Texo 本地低功耗路由（NPU→GPU→CPU 编码、CPU 解码），未装原生运行时回退包内 CPU；Pix2Text 服务备选。
- 单页/连续/双页均支持移动、双指缩放、滚轮和缩放按钮；阅读预览保持旧位图直到新绘制完成。连续页和缩略图只挂载视区附近页面，长文档滚动时保持完整页码和排序。
- 框选 OCR（O）：PP-OCRv4 本地 NPU/GPU/CPU 识别（实验）、Tesseract 回退、Texo 公式识别、HTTP/图像 LLM 接口，远程文字 OCR 失败回退本地；结果可修改、复制、翻译和朗读。
- Piper 中英本地语音：0.2.11 默认尝试原生 NPU→GPU→CPU 波形生成，音素/时长/尾段保留 CPU；可切回内置 WASM、系统离线声音或 HTTP/兼容语音 API。支持暂停/继续/停止和语速调整，原生不可用回退 Piper WASM，模型不可用尝试系统离线声音。
- F11/顶部按钮切换桌面全屏、Esc 退出；可拖动的 simple-keyboard 悬浮键盘，尺寸调节位于默认收起的二级设置；LaTeX 快捷符号和左上角 Shift 字符预览，Shift+反斜杠输入竖线。
- 各视图共享 48MiB 背景/瓦片缓存，两路绘制优先队列，取消离开视区的绘制；高倍率只为视区附近补充高清细节，每页细节层最多 600 万像素，快速预览不加载瓦片；已完成笔迹几何复用，减少反复缩放和对象编辑的重复计算。

## 本地模型与翻译

```powershell
npm run model:texo
npm run model:translation
npm run model:reading
npm start
```

模型从脚本固定的版本下载，运行时仅加载本机资源。Texo 约 80MB；OPUS 两方向约 239MB；Tesseract 两语种约 6.6MB、PP-OCRv4 三模型约 16.2MB，Piper 两声音约 83.8MB，另有音素与 WASM 运行时。当前设备已准备这些资源。模型按需加载、闲置两分钟释放，内置 WASM 路径不需要 Python 服务，可选加速另使用隔离运行时。翻译合并 PDF 普通换行并保留空行段落；原文复制保留排版。OCR 和语音中英以外的语言仍需相应模型或 API。

默认对文字输入框设置 `inputmode=none`，使用悬浮键盘以抑制 Windows 触摸键盘；可勾选“使用系统触摸键盘”恢复。它不会关闭 Windows 输入服务；某些驱动/系统策略仍可能自行唤起系统键盘。悬浮键盘当前为英文和 LaTeX 布局，中文输入可切回系统输入法。桌面全屏通过 Electron 桥接，主进程更新后需重新打开桌面窗口。

在线 Google：未填密钥时打开官方 Google 翻译网页；启用 Cloud Translation 的 API Key 可使译文直接进入浮窗。自定义 HTTP 返回 `translatedText`/`translation`，LLM 接口兼容聊天消息格式。密钥仅保留当前会话；网络接口 15 秒超时后尝试本地回退。Google 网页在外部浏览器中运行，无法检测其网络失败，可用浮窗中的“本地翻译”按钮切回内置模型。

## 手写公式备选服务（可选）

需要独立 Python 3.11/3.12 环境，模型不会随桌面主程序捆绑。CPU 运行，不需要 CUDA。

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r backend/requirements.txt
.venv\Scripts\python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

首次识别会下载开源 `mfr` 模型；可设置 `SURFACETAB_MODEL_DIR` 使用预下载目录。只实例化独立公式识别器，不加载文本、版面或表格模型。模型缓存后可离线运行。模型规模、占用和手写准确率应以实际下载版本及手写样本实测为准，尚未做 设备 CPU 性能承诺。没有服务时仍可手动输入 LaTeX、预览和插入公式。

## 操作

P 钢笔 / B 圆珠笔 / N 铅笔 / H 荧光笔 / E 擦除 / V 移动 / T 选文 / S 对象；Ctrl+Z 撤销，Ctrl+Y 重做，Ctrl+S 保存工程，Ctrl+O 打开；左右箭头翻页。背面笔擦识别标准 `button=5` 或 `buttons & 32`，不更改当前选中的笔。设置面板显示原始压感、擦除信号和采样信息。

## 边界

这是 PDF 标注/页面管理基础版，尚不修改原 PDF 文字和已有对象。擦除作用于应用新增的笔迹和草图/公式，不删除原 PDF 内容。新草图/公式居中放置，可调整位置、尺寸和再次编辑。PDF 导出使用高分辨率 PNG，草图显示采用 SVG；公式极限放大仍有栅格边界。纸张点阵/横线不导出。签名、表单、加密 PDF 和原 PDF 超链接/注释不保证通过重新嵌入保留。超复杂页面首次解析仍需要时间，快速缩放依赖已有预览。

压感与背面擦除的协议行为有自动化测试；实际笔硬件和驱动仍需真笔验证。没有实现 Slim Pen 振动反馈。

## 本地低功耗公式识别

公式画板和区域公式识别默认优先 OpenVINO：NPU 编码 → GPU 编码 → CPU；解码器用 2 线程 CPU。没有原生运行时则自动使用内置 CPU，无需为基础功能安装 Python。当前电脑已经准备了隔离运行时，识别时按需启动。

其它电脑首次安装需要 Python 3.10 x64。在已解压应用目录执行：

```powershell
.\backend\start-openvino.ps1 -Install
```

安装过程需要联网；服务启动后仅本机离线识别。便携 EXE 使用者可从发布目录的 `win-unpacked/backend` 执行该脚本，之后正常启动 EXE 即可自动连接/启动。公式 → 本地加速设置可手动选择设备并检查连接。该策略优先 NPU，不代表已测量电池耗电。文字 OCR 从 0.2.10 起默认尝试可选 PP-OCRv4 加速，运行 `backend/start-openvino.ps1 -Install -Ocr` 准备组件，未安装时回退 Tesseract。详见 [OCR 原生实现](docs/OCR-NATIVE.md)。翻译另有可选实验性 OpenVINO 后端，选词 → 翻译 → 后端设置 → 本地实验。默认保留内置 WASM，实验译文需核对公式、数字和术语。详见 [OPUS 原生实验](docs/OPUS-NATIVE.md)。

朗读在 0.2.11 默认尝试可选 Piper OpenVINO，复用相同中英声音和上述基础运行时，无新增 Python 依赖。选词 → 翻译 → 后端设置 → 朗读后端，可选择设备或内置 Piper。未装组件或旧版服务不支持时自动回退 WASM；忙碌、取消和超时不会重复合成。详细实现与测量边界见 [Piper 原生实验](docs/PIPER-NATIVE.md)。
